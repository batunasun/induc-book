12. Индукцлэх тохиромжтой хувьсагчийг сонгох

Эерэг бүхэл тоотой холбоотой өгүүлбэрүүд заримдаа олон хувьсагчийг агуулдаг. Тэдгээрийг математикийн индукц ашиглан батлахдаа эхлээд аль хувьсагчаар нь индукцлэх нь зөв болохыг шийдэх хэрэгтэй.

NoteЖишээ 1

m, n \in \mathbf{N}^* байг. Дурын эерэг бодит x_1, \dots, x_n; \; y_1, \dots, y_n тоонуудын хувьд хэрэв x_i + y_i = 1 (i = 1, 2, \dots, n) бол (1 - x_1 \cdots x_n)^m + (1 - y_1^m)(1 - y_2^m)\cdots(1 - y_n^m) \geqslant 1 \tag{1} биелэхийг батал.

Баталгаа. n-ээр математикийн индукц хэрэглэе.
n = 1 үед өгөгдсөн нөхцөлөөс (1 - x_1)^m + (1 - y_1^m) = y_1^m + (1 - y_1^m) = 1 тул (1) биелнэ.
Одоо n - 1 (n \geqslant 2) үед (1) үнэн гэж таамаглаад n тохиолдлыг авч үзье: \begin{aligned} &(1 - x_1 \cdots x_n)^m + (1 - y_1^m)\cdots(1 - y_n^m) \\ &= (1 - x_1 \cdots x_{n-1}(1 - y_n))^m + (1 - y_1^m)\cdots(1 - y_n^m) \\ &\geqslant (1 - x_1 \cdots x_{n-1} + x_1 \cdots x_{n-1} y_n)^m + \big(1 - (1 - x_1 \cdots x_{n-1})^m\big)(1 - y_n^m). \end{aligned} a = 1 - x_1 \cdots x_{n-1}, b = y_n гэж тэмдэглэе. Дээрх тэнцэтгэл бишээс (1)-ийг n үед батлахын тулд зөвхөн аливаа a, b \in (0, 1) хувьд (a + b - ab)^m + (1 - a^m)(1 - b^m) \geqslant 1 буюу (a + b - ab)^m \geqslant a^m + b^m - a^m b^m \tag{2} биелэхийг батлахад хангалттай.

(2)-ыг батлахын тулд m-ээр индукцлэе.
m = 1 үед (2) биелэх нь илэрхий. Одоо m - 1 (m \geqslant 2) үед (2) үнэн гэж таамаглая. Тэгвэл: \begin{aligned} &(a + b - ab)^m - a^m - b^m + a^m b^m \\ &\geqslant (a^{m-1} + b^{m-1} - a^{m-1} b^{m-1})(a + b - ab) - a^m - b^m + a^m b^m \\ &= 2a^m b^m + a b^{m-1} + b a^{m-1} - a^m b^{m-1} - a^{m-1} b^m - a^m b - a b^m \\ &= (b^{m-1} - b^m)(a - a^m) + (a^{m-1} - a^m)(b - b^m). \end{aligned} a, b \in (0, 1) гэдгийг тооцвол b^{m-1} \geqslant b^m, a \geqslant a^m, a^{m-1} \geqslant a^m, b \geqslant b^m байна.
Тиймээс (a + b - ab)^m \geqslant a^m + b^m - a^m b^m буюу (2) нь m үед биелнэ.
Эндээс (1) үнэн гэдэг нь мөрдөн гарна.

Тайлбар. Энэ нь эерэг бүхэл хоёр хувьсагч агуулсан бодлого юм. (1)-ийн зүүн талын хоёр дахь нэмэгдэхүүн нь n-ээр индукцлэхэд илүү хялбар харагдаж байгаа тул m-ийг тогтмол гэж үзээд эхлээд n-ээр индукцлэх санаа жам ёсоор төрж байна.

NoteЖишээ 2

Аливаа m, n \in \mathbf{N}^* хувьд S(m, n) = \sum_{i=0}^{2^{n-1} - 1} \left(\tan \frac{(2i + 1)\pi}{2^{n+1}}\right)^{2m} нь эерэг бүхэл тоо болохыг батал.

Баталгаа. n-ийг индукцлэх хувьсагчаар сонгон авъя.
n = 1 үед S(m, 1) = \left(\tan \frac{\pi}{4}\right)^{2m} = 1 тул бүх m \in \mathbf{N}^* хувьд өгүүлбэр үнэн.
Одоо n - 1 үед бүх m \in \mathbf{N}^* хувьд өгүүлбэр үнэн гэж таамаглаад n тохиолдлыг авч үзье.
\cot 2\alpha = \frac{1 - \tan^2 \alpha}{2\tan \alpha} = \frac{1}{2}(\cot \alpha - \tan \alpha) гэдгээс: \tan^2\left(\frac{\pi}{2} - 2\alpha\right) = \frac{1}{4}(\cot \alpha - \tan \alpha)^2 = \frac{1}{4}(\tan^2 \alpha + \cot^2 \alpha - 2). Иймд анхны нийлбэрийн эхний ба сүүлийн гишүүдийг хослон (өөрөөр хэлбэл, i-р болон (2^{n-1} - 1 - i)-р гишүүдийн нийлбэрээр) дахин бичвэл: \begin{aligned} S(1, n) &= \frac{1}{2}\sum_{i=0}^{2^{n-1} - 1} \left(\tan^2 \frac{(2i + 1)\pi}{2^{n+1}} + \tan^2 \frac{(2(2^{n-1} - 1 - i) + 1)\pi}{2^{n+1}}\right) \\ &= \frac{1}{2}\sum_{i=0}^{2^{n-1} - 1} \left(\tan^2 \frac{(2i + 1)\pi}{2^{n+1}} + \tan^2\left(\frac{\pi}{2} - \frac{(2i + 1)\pi}{2^{n+1}}\right)\right) \\ &= \frac{1}{2}\sum_{i=0}^{2^{n-1} - 1} \left(\tan^2 \frac{(2i + 1)\pi}{2^{n+1}} + \cot^2 \frac{(2i + 1)\pi}{2^{n+1}}\right) \\ &= \frac{1}{2}\sum_{i=0}^{2^{n-1} - 1} \left(4\tan^2 \frac{(2i + 1)\pi}{2^n} + 2\right) \\ &= 2\sum_{i=0}^{2^{n-1} - 1} \tan^2 \frac{(2i + 1)\pi}{2^n} + 2^{n-1} \\ &= 2\sum_{i=0}^{2^{n-2} - 1} \left(\tan^2 \frac{(2i + 1)\pi}{2^n} + \tan^2 \frac{(2(2^{n-1} - 1 - i) + 1)\pi}{2^n}\right) + 2^{n-1} \\ &= 2\sum_{i=0}^{2^{n-2} - 1} \left(\tan^2 \frac{(2i + 1)\pi}{2^n} + \tan^2\left(\pi - \frac{(2i + 1)\pi}{2^n}\right)\right) + 2^{n-1} \\ &= 4\sum_{i=0}^{2^{n-2} - 1} \tan^2 \frac{(2i + 1)\pi}{2^n} + 2^{n-1} = 4S(1, n - 1) + 2^n. \end{aligned} Иймд S(1, n) \in \mathbf{N}^*.

Дараа нь S(1, n), S(2, n), \dots, S(m - 1, n) нь бүгд эерэг бүхэл тоонууд гэж таамаглая. Тэгвэл S(m, n)-ийг авч үзэхийн тулд аливаа k \in \mathbf{N} хувьд Ньютоны биномын теорем ёсоор (x + x^{-1})^k = C_k^0(x^k + x^{-k}) + C_k^1(x^{k-1} + x^{-(k-1)}) + \dots \tag{1} биелэхийг ажиглая. Тиймээс (1)-ээс: \begin{aligned} \left(\frac{1}{4}(x + x^{-1} - 2)\right)^m &= \frac{1}{4^m}\sum_{k=0}^m C_m^k (x + x^{-1})^k \cdot (-2)^{m-k} \\ &= \frac{1}{4^m}\big((x^m + x^{-m}) + b_1(x^{m-1} + x^{-(m-1)}) + \dots + b_{m-1}(x + x^{-1}) + b_m\big), \end{aligned} энд b_1, \dots, b_m \in \mathbf{Z}.

Дээрх тэгшитгэлд x = \tan^2 \frac{(2i + 1)\pi}{2^{n+1}} гэж орлуулаад i = 0, 1, 2, \dots, 2^{n-2} - 1 утгуудаар нийлбэрлэе. S(1, n)-ийг тооцоолсонтой ижил хувиргалт хийвэл: S(m, n - 1) = \frac{1}{4^m}\big(S(m, n) + b_1 S(m - 1, n) + \dots + b_{m-1} S(1, n) + b_m\big), эндээс: S(m, n) = 4^m \cdot S(m, n - 1) - b_1 S(m - 1, n) - \dots - b_{m-1} S(1, n) - b_m. Тиймээс S(m, n) \in \mathbf{Z} болно. S(m, n)-ийн гишүүн бүр тэгээс их тул S(m, n) \in \mathbf{N}^* байна.
Дээрхийг нэгтгэвэл аливаа m, n \in \mathbf{N}^* хувьд бүх S(m, n) нь эерэг бүхэл тоонууд болно. Ийнхүү өгүүлбэр батлагдлаа.

Тайлбар. Үндсэндээ бид n - 1-ээс n рүү шилжих индукцийн алхмын явцад хоёр дахь хувьсагч m-ээр индукцлэх аргыг хэрэглэлээ. Хоёр хувьсагч оролцсон өгүүлбэрүүдийг математикийн индукцээр батлахад бидний хэрэглэсэн энэ арга нь түгээмэл ашиглагддаг үндсэн аргуудын нэг юм.

NoteЖишээ 3

Сөрөг биш бүхэл a_1, a_2, \dots, a_t тоонууд 1 \leqslant i, j \leqslant t, i + j \leqslant t үед a_i + a_j \leqslant a_{i+j} \leqslant a_i + a_j + 1 нөхцөлийг хангадаг байг. Бүх n \in \{1, 2, \dots, t\} хувьд a_n = [nx] биелэхээр тийм x \in \mathbf{R} тоо оршихыг батал.

Баталгаа. n = 1, 2, \dots, t хувьд I_n = \left[\frac{a_n}{n}, \frac{a_n + 1}{n}\right) гэж тэмдэглэе. Бид x \in \bigcap_{n=1}^t I_n \tag{1} нөхцөлийг хангах бодит x тоо оршино гэдгийг батлах шаардлагатай.
L = \max_{1 \leqslant n \leqslant t} \frac{a_n}{n}, U = \min_{1 \leqslant n \leqslant t} \frac{a_n + 1}{n} гэе. Хэрэв бид L < U гэдгийг баталж чадвал \bigcap_{n=1}^t I_n = [L, U) болох тул (1) биелнэ. Үүний тулд дурын m, n \in \{1, 2, \dots, t\} хувьд \frac{a_n}{n} < \frac{a_m + 1}{m}, өөрөөр хэлбэл m a_n < n(a_m + 1) \tag{2} биелэхийг батлахад хангалттай.

Дараа нь m + n нийлбэрээр индукцлэн (2)-ыг баталъя.
n + m = 2 үед m = n = 1 болох тул (2) илэрхий биелнэ. n + m \leqslant k нөхцөлийг хангах бүх эерэг бүхэл (m, n) хосуудын хувьд (2) биелнэ гэж таамаглая. n + m = k + 1 үед хэрэв m = n бол (2) илэрхий биелнэ.
- Хэрэв m > n бол индукцийн таамаглал ёсоор (m - n)a_n < n(a_{m-n} + 1) байна. Бодлогын нөхцөлийн a_i + a_j \leqslant a_{i+j} тэнцэтгэл бишээс n(a_{m-n} + a_n) \leqslant n a_m гэдгийг мэднэ. Тиймээс m a_n < n(a_m + 1) буюу (2) биелнэ. - Хэрэв m < n бол индукцийн таамаглал ёсоор m a_{n-m} < (n - m)(a_m + 1) байна. Бодлогын нөхцөлийн a_{i+j} \leqslant a_i + a_j + 1 тэнцэтгэл бишээс m a_n \leqslant m(a_m + a_{n-m} + 1) гэж гарна. Иймд m a_n < n(a_m + 1) буюу (2) биелнэ.

Дээрхийг нэгтгэвэл дурын m, n \in \{1, 2, \dots, t\} хувьд (2) ямагт биелнэ.

Тайлбар. Ерөнхий тохиолдолд аливаа x \in \mathbf{R}, i, j \in \mathbf{N}^* хувьд [ix] + [jx] \leqslant [(i + j)x] \leqslant [ix] + [jx] + 1 ямагт биелдэг. Энэ нь үндсэндээ бүхэл хэсгийн функцийн чанар бөгөөд бид үүнийг урвуу чиглэлд нь авч үзсэнээр энэ бодлогын дүгнэлтэд хүрлээ. Энэ бодлогын дүгнэлт нь дурын төгсгөлөг тооны гишүүдийн хувьд л хүчинтэй бөгөөд бодлогын нөхцөлийг хангах төгсгөлгүй a_1, a_2, \dots дарааллын хувьд ийм x тоо олдохгүй гэдгийг анхаарна уу.
Арга зүйн талаас харвал m + n нийлбэрээр индукцлэх стратеги нь тун тохиромжтой бөгөөд оновчтой байлаа.

NoteЖишээ 4

m, n нь ялгаатай эерэг бүхэл тоонууд байг. Бүхэл тооноос тогтох нэгэн дараалал нь дурын дараалсан m гишүүний нийлбэр нь сөрөг, харин дурын дараалсан n гишүүний нийлбэр нь эерэг байх нөхцөлийг хангадаг. Энэ дараалал хамгийн олондоо хэдэн гишүүнтэй байж болох вэ?

Бодолт. (m, n) = d, m = m_1 d, n = n_1 d гэвэл (m_1, n_1) = 1 болно. Мөн a_1, \dots, a_t дараалал бүх нөхцөлийг хангадаг гэе. A_i = a_{(i-1)d + 1} + \dots + a_{id} (i = 1, 2, \dots) гэж тэмдэглэе.

Нэг талаас, хэрэв t \geqslant (m_1 + n_1 - 1)d бол дараах тоон хүснэгтийг авч үзье: \begin{array}{cccc} A_1, & A_2, & \dots, & A_{m_1}; \\ A_2, & A_3, & \dots, & A_{m_1 + 1}; \\ \dots & \dots & \dots & \dots \\ A_{n_1}, & A_{n_1 + 1}, & \dots, & A_{n_1 + m_1 - 1}. \end{array} Өгөгдсөн нөхцөл ёсоор мөр бүрийн тоонуудын нийлбэр сөрөг, харин багана бүрийн тоонуудын нийлбэр эерэг байна. Энэ хүснэгтийн бүх тооны нийлбэрийг мөрөөр нь нэмбэл сөрөг, баганаар нь нэмбэл эерэг гарч өөр хоорондоо зөрчилдөнө. Тиймээс t \leqslant (m_1 + n_1 - 1)d - 1, өөрөөр хэлбэл t \leqslant m + n - (m, n) - 1 гэж дүгнэж болно.

Нөгөө талаас, шаардлагыг хангах m + n - (m, n) - 1 урттай бүхэл тоон дараалал оршино гэдгийг батлах шаардлагатай. Үүний тулд дараах өгүүлбэрийг баталъя:

Өгүүлбэр. d \in \mathbf{N}^* бөгөөд s, t нь (s, t) = 1 нөхцөлийг хангах ялгаатай эерэг бүхэл тоонууд бол дурын дараалсан sd гишүүний нийлбэр нь сөрөг, дурын дараалсан td гишүүний нийлбэр нь эерэг байх (s + t - 1)d - 1 урттай рационал тоон дараалал оршино. (Анхаар: Энэ өгүүлбэр дэх дарааллын тоо бүрийг бүх гишүүдийн ерөнхий хуваариар үржүүлбэл бидний хүссэн бүхэл тоон дараалал гарна.)

\max\{s, t\} = r хэмжигдэхүүнээр математикийн индукц хэрэглэе.
\max\{s, t\} = 2 үед ерөнхий чанарыг алдагдуулахгүйгээр s = 2, t = 1 гэе (эс тэгвээс дарааллын тоо бүрийг -1-ээр үржүүлнэ); тэгвэл 2d - 1 ширхэг дурын эерэг рационал тоог авахад өгүүлбэрийг хангах дараалал үүснэ.

\max\{s, t\} < r (r \geqslant 3) үед өгүүлбэр зөв гэж таамаглаад \max\{s, t\} = r тохиолдлыг авч үзье.
Ерөнхий чанарыг алдагдуулахгүйгээр s > t гэж үзээд (s - t, t) = 1 гэдгийг ажиглая. Тэгвэл индукцийн таамаглал ёсоор дурын дараалсан (s - t)d гишүүний нийлбэр нь сөрөг, дурын дараалсан td гишүүний нийлбэр нь эерэг байх рационал тоон b_1, b_2, \dots, b_{(s-1)d - 1} дараалал оршино. Дараах тэнцэтгэл бишийн системүүд биелэхээр тийм рационал a_1, a_2, \dots, a_{td} тоонууд оршино гэдгийг баталъя: \begin{cases} a_{d+1} + \dots + a_1 + b_1 + \dots + b_{(s-1)d - 1} < 0, \\ a_{d+2} + \dots + a_1 + b_1 + \dots + b_{(s-1)d - 2} < 0, \\ \dots \\ a_{td} + \dots + a_1 + b_1 + \dots + b_{(s-t)d} < 0 \tag{1} \end{cases} ба \begin{cases} a_{td} + \dots + a_1 > 0, \\ a_{td-1} + \dots + a_1 + b_1 > 0, \\ \dots \\ a_1 + b_1 + \dots + b_{td - 1} > 0. \tag{2} \end{cases} Тэгвэл a_{td}, a_{td-1}, \dots, a_1, b_1, \dots, b_{(s-1)d - 1} дараалал нь (s + t - 1)d - 1 урттай бөгөөд өгүүлбэрийг хангах дараалал болно. Иймд өгүүлбэр батлагдана.

Үнэн хэрэгтээ дээрх тэнцэтгэл бишийн системүүдийг нэгэн зэрэг биелүүлэхийн тулд эхлээд a_1, a_2, \dots, a_d рационал тоонуудыг \begin{gathered} a_1 > -(b_1 + \dots + b_{td - 1}), \quad a_2 > -(a_1 + b_1 + \dots + b_{td - 2}), \quad \dots, \\ a_d > -(a_{d-1} + \dots + a_1 + b_1 + \dots + b_{(t-1)d}) \end{gathered} байхаар сонгож аваад, дараа нь a_{d+1} рационал тоог -(a_d + \dots + a_1 + b_1 + \dots + b_{(t-1)d - 1}) < a_{d+1} < -(a_d + \dots + a_1 + b_1 + \dots + b_{(s-1)d - 1}) \tag{3} нөхцөлийг хангахаар сонгоход хангалттай.
(3)-ийн баруун талаас зүүн талыг нь хасахад -(b_{(t-1)d} + \dots + b_{(s-1)d - 1}) > 0 (энд бид индукцийн таамаглалыг ашиглалаа) гэдгийг ажиглая. Тиймээс нөхцөлийг хангах a_{d+1} тоо заавал оршино. Үүнтэй яг ижил аргаар (1) ба (2) тэнцэтгэл бишийн системүүдийг хангах a_1, \dots, a_{td} рационал тоонууд оршино гэж дүгнэж болно.

Үндсэн асуултдаа эргэн оръё. Нөхцөлийг хангах бүхэл тоон дараалал хамгийн олондоо m + n - (m, n) - 1 гишүүнтэй байна.

Тайлбар. Энэ бодлогын m = 11, n = 6 тохиолдол урьд нь олимпиадын бодлого болж гарч байсан. m = 11, n = 6 үед жишээ олоход хялбар боловч ерөнхий m, n-ийн хувьд жишээ байгуулах нь хэцүү юм. 2000 онд Хятадын Үндэсний математикийн олимпиадын бэлтгэл багийн сорилгод энэ жишээ ирэхэд тун цөөхөн сурагч зөв бодсон байдаг.
