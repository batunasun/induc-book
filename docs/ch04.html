4. Дарааллын ерөнхий гишүүн ба нийлбэр олох

Тодорхой эрэмбээр байрлуулсан тоонуудын эгнээг дараалал гэнэ. Дараалал дахь тоо бүрийг гишүүн гэх бөгөөд тэдгээрийг дарааллаар нь нэгдүгээр гишүүн, хоёрдугаар гишүүн, …, n-р гишүүн, … гэж нэрлэдэг.

Дарааллын ерөнхий хэлбэрийг a_1, a_2, \dots, a_n, \dots гэж бичээд \{a_n\} гэж тэмдэглэнэ. Хэрэв \{a_n\} дарааллын n-р гишүүн a_n-ийг алгебрийн томьёогоор илэрхийлж болдог бол уг томьёог ерөнхий гишүүний томьёо гэнэ.

Дээрх тодорхойлолтоос үзвэл дараалал нь үндсэндээ эерэг бүхэл тооны олонлог дээр тодорхойлогдсон функц юм. Дарааллын ерөнхий гишүүний томьёог олох болон эхний n гишүүний нийлбэрийг бодох нь холбогдох бодлогуудын хамгийн суурь бөгөөд түгээмэл хэсэг билээ.

\{a_n\} дарааллын эхний n гишүүний нийлбэрийг S_n гэж тэмдэглэе. Тэгвэл түүний ерөнхий гишүүнтэй холбогдох хамаарал нь дараах байдалтай байна: a_1 = S_1, \quad a_n = S_n - S_{n-1}, \quad n = 2, 3, \dots

Цаашдын хэлэлцүүлэгт хялбар болгох үүднээс дараах ойлголтуудыг оруулъя: - Хэрэв дараалал төгсгөлөг тооны гишүүнтэй бол түүнийг төгсгөлөг дараалал, эсрэг тохиолдолд төгсгөлгүй дараалал гэнэ. - Хэрэв \{a_n\} дараалал нь аливаа n \in \mathbf{N}^* хувьд a_n < a_{n+1} (харгалзан a_n > a_{n+1}) нөхцөлийг хангадаг бол түүнийг өсөх (харгалзан буурах) дараалал гэнэ. Хэрэв a_n \leqslant a_{n+1} (харгалзан a_n \geqslant a_{n+1}) бол үл буурах (харгалзан үл өсөх) дараалал гэнэ. - Хэрэв аливаа n \in \mathbf{N}^* хувьд |a_n| \leqslant M байх M тогтмол тоо оршдог бол \{a_n\} бодит дарааллыг зааглагдсан дараалал гэнэ.

NoteЖишээ 1

\{a_n\} дараалал нь аливаа сөрөг биш бүхэл m, n (m \geqslant n) тоонуудын хувьд a_{m+n} + a_{m-n} = \frac{1}{2}(a_{2m} + a_{2n}) нөхцөлийг хангадаг. Мөн a_1 = 1 бол дарааллын ерөнхий гишүүний томьёог ол.

Бодолт. Бодлогын нөхцөлөөс аливаа m \in \mathbf{N} хувьд \frac{1}{2}(a_{2m} + a_{2m}) = a_{2m} + a_0 = 2(a_m + a_m) биелэх тул a_0 = 0 ба a_{2m} = 4a_m гэж гарна.
a_1 = 1 гэдгийг тооцвол n \in \{0, 1, 2\} үед a_n = n^2 биелэхийг харж болно. Тэгвэл энэ нь дарааллын ерөнхий гишүүний томьёо мөн үү?
Хэрэв a_{m-1} = (m - 1)^2, a_m = m^2 бол нөхцөл ёсоор: a_{m+1} + a_{m-1} = \frac{1}{2}(a_{2m} + a_2) = \frac{1}{2}(4a_m + 4a_1). Иймд: a_{m+1} = 2a_m - a_{m-1} + 2a_1 = 2m^2 - (m - 1)^2 + 2 = m^2 + 2m + 1 = (m + 1)^2. Тэгвэл математикийн индукцийн зарчим ёсоор бүх n \in \mathbf{N}^* хувьд a_n = n^2 байна.
Дүгнэж хэлбэл, дарааллын ерөнхий гишүүний томьёо нь a_n = n^2 юм.

Тайлбар. Дарааллын бодлогуудад өгөгдсөн нөхцөлөөс ерөнхий гишүүний томьёог олох асуулт түгээмэл тааралддаг. Дараалал нь эерэг бүхэл тооны олонлог дээр тодорхойлогдсон функц тул энэ нь мөн тусгай хэлбэрийн функцэн тэгшитгэлийн бодлого болдог.

NoteЖишээ 2

n нь өгөгдсөн эерэг бүхэл тоо байг. a_0, a_1, a_2, \dots, a_n дараалал нь a_0 = \frac{1}{2}, a_k = a_{k-1} + \frac{a_{k-1}^2}{n} (k = 1, 2, \dots, n) нөхцөлийг хангадаг бол 1 - \frac{1}{n} < a_n < 1 болохыг батал.

Баталгаа. Бодлогын нөхцөлөөс аливаа 1 \leqslant k \leqslant n хувьд a_{k-1} < a_k гэдэг нь мөрдөн гарна. Иймд бүх 0 \leqslant k \leqslant n хувьд a_k > 0 байна.
Бодлогын томьёог хувиргавал: \frac{1}{a_k} = \frac{n}{n a_{k-1} + a_{k-1}^2} = \frac{1}{a_{k-1}} - \frac{1}{a_{k-1} + n}. Гишүүдийг шилжүүлбэл: \frac{1}{a_{k-1} + n} = \frac{1}{a_{k-1}} - \frac{1}{a_k}. \tag{1} (1) тэнцэтгэлийг k = 1-ээс n хүртэл нэмбэл: \begin{aligned} \sum_{k=1}^n \frac{1}{a_{k-1} + n} &= \left(\frac{1}{a_0} - \frac{1}{a_1}\right) + \left(\frac{1}{a_1} - \frac{1}{a_2}\right) + \dots + \left(\frac{1}{a_{n-1}} - \frac{1}{a_n}\right) \\ &= \frac{1}{a_0} - \frac{1}{a_n} = 2 - \frac{1}{a_n}. \end{aligned} a_{k-1} > 0 гэдгийг тооцвол: 2 - \frac{1}{a_n} = \sum_{k=1}^n \frac{1}{a_{k-1} + n} < \sum_{k=1}^n \frac{1}{n} = 1. Иймд a_n < 1.
a_k > a_{k-1} тул 0 < a_0 < a_1 < \dots < a_n < 1 байна. Тиймээс: 2 - \frac{1}{a_n} = \sum_{k=1}^n \frac{1}{a_{k-1} + n} > \sum_{k=1}^n \frac{1}{1 + n} = \frac{n}{n + 1}. Эндээс: a_n > \frac{n + 1}{n + 2} = 1 - \frac{1}{n + 2} > 1 - \frac{1}{n}. Ийнхүү өгүүлбэр батлагдлаа.

Тайлбар. Томьёоны хоёр талын урвууг авах арга нь гишүүдийг задлах санаанаас үүдэлтэй бөгөөд дарааллын нийлбэр олоход өмнөх ба дараагийн гишүүдийг харилцан хураахын тулд түгээмэл хэрэглэгддэг.

NoteЖишээ 3

n \in \mathbf{N}^* хувьд a_n = \frac{n}{(n - 1)^{\frac{4}{3}} + n^{\frac{4}{3}} + (n + 1)^{\frac{4}{3}}} байг. Дараах тэнцэтгэл биш биелэхийг батал: a_1 + a_2 + \dots + a_{999} < 50.

Баталгаа. Ерөнхий санаа нь «хэсгээс бүхэл рүү» шилжих арга юм. Үүний тулд бид a_n-ийг зохистойгоор томруулж үнэлнэ. Ингэснээр гишүүдийг задалж, хураах боломжтой болно.

x^3 - y^3 = (x - y)(x^2 + xy + y^2) адилтгалыг ашиглахын тулд x = (n + 1)^{\frac{2}{3}}, y = (n - 1)^{\frac{2}{3}} гэж авъя. Тэгвэл xy = (n^2 - 1)^{\frac{2}{3}} < n^{\frac{4}{3}} байна. Иймд: \begin{aligned} a_n < \frac{n}{x^2 + xy + y^2} &= \frac{n(x - y)}{x^3 - y^3} \\ &= \frac{n(x - y)}{(n + 1)^2 - (n - 1)^2} = \frac{1}{4}(x - y) \\ &= \frac{1}{4}\left((n + 1)^{\frac{2}{3}} - (n - 1)^{\frac{2}{3}}\right). \end{aligned} Тиймээс: \begin{aligned} a_1 + \dots + a_{999} &< \frac{1}{4}\sum_{n=1}^{999} \left((n + 1)^{\frac{2}{3}} - (n - 1)^{\frac{2}{3}}\right) \\ &= \frac{1}{4}\left(\sum_{n=2}^{1000} n^{\frac{2}{3}} - \sum_{n=0}^{998} n^{\frac{2}{3}}\right) \\ &= \frac{1}{4}\left(1000^{\frac{2}{3}} + 999^{\frac{2}{3}} - 1\right) \\ &< \frac{1}{2} \times 1000^{\frac{2}{3}} = 50. \end{aligned} Ийнхүү өгүүлбэр батлагдлаа.

Тайлбар. Дарааллын нийлбэртэй холбоотой тэнцэтгэл бишийг бодохдоо эхлээд гишүүдийг нь багасгаж эсвэл томруулж үнэлээд дараа нь нэмэх нь чухал арга юм.

NoteЖишээ 4

k \in \mathbf{N}^* ба k \equiv 3 \pmod{4} байг. Дараах нийлбэрийг тодорхойлъё: S_n = C_n^0 - C_n^2 k + C_n^4 k^2 - C_n^6 k^3 + \dots Аливаа n \in \mathbf{N}^* хувьд 2^{n-1} \mid S_n болохыг батал.

Баталгаа. Комплекс тоо ашиглан баталъя.
S_n-ийн тодорхойлолт болон Ньютоны биномын томьёоноос S_n = \operatorname{Re}(1 + \sqrt{k}\,\mathrm{i})^n гэдгийг гаргаж болно (энд \mathrm{i} нь хуурмаг нэгж, харин \operatorname{Re}(z) нь z комплекс тооны бодит хэсгийг тэмдэглэнэ).
Иймд: S_n = \frac{1}{2}\left((1 + \sqrt{k}\,\mathrm{i})^n + (1 - \sqrt{k}\,\mathrm{i})^n\right). Цаашилбал x = 1 + \sqrt{k}\,\mathrm{i}, y = 1 - \sqrt{k}\,\mathrm{i} гэж тэмдэглэвэл: \begin{aligned} S_{n+2} &= \frac{1}{2}(x^{n+2} + y^{n+2}) \\ &= \frac{1}{2}\left((x^{n+1} + y^{n+1})(x + y) - xy(x^n + y^n)\right) \\ &= (x + y)S_{n+1} - xy S_n \\ &= 2S_{n+1} - (1 + k)S_n. \end{aligned} Мөн S_1 = 1, S_2 = 1 - k байна.
Одоо аливаа n \in \mathbf{N}^* хувьд 2^{n-1} \mid S_n болохыг баталъя.
k \equiv 3 \pmod{4} гэдгийг тооцвол n = 1, 2 үед өгүүлбэр үнэн. n ба n + 1 үед өгүүлбэр үнэн, өөрөөр хэлбэл 2^{n-1} \mid S_n ба 2^n \mid S_{n+1} гэж таамаглая. n + 2 тохиолдлын хувьд 1 + k \equiv 1 + 3 \equiv 0 \pmod{4} болон S_{n+2} = 2S_{n+1} - (1 + k)S_n гэдгээс 2^{n+1} \mid S_{n+2} болно (учир нь 2^{n+1} \mid 2S_{n+1} ба 2^{n+1} \mid (1 + k)S_n).
Тиймээс аливаа n \in \mathbf{N}^* хувьд 2^{n-1} \mid S_n байна.

Тайлбар. Бид нөхцөлөөс эхлэн тохирох хувиргалтуудыг хийж, рекуррент хамаарлыг тогтоогоод эцэст нь математикийн индукцийг ашиглалаа. Ийнхүү бодлогыг цэгцтэй сэтгэлгээгээр нэг амьсгаагаар бодлоо. Энэ санааг хэрэгжүүлэхэд мөн тун хялбар юм.

NoteЖишээ 5

Эерэг бүхэл тооны өсөх \{a_n\} дарааллын эхний хэдэн гишүүн нь: 1; \; 2, 4; \; 5, 7, 9; \; 10, 12, 14, 16; \; 17, \dots Бүтэц нь нэг сондгой тоо, хоёр тэгш тоо, гурван сондгой тоо, дөрвөн тэгш тоо гэх мэтээр үргэлжилнэ.
Аливаа n \in \mathbf{N}^* хувьд a_n = 2n - \left[\frac{1 + \sqrt{8n - 7}}{2}\right] болохыг батал.

Баталгаа. Хэрэв n = 1 + 2 + \dots + k байх k \in \mathbf{N}^* оршдог бол n-ийг гурвалжин тоо гэж нэрлэе.
Одоо \{b_n\} дарааллыг дараах байдлаар тодорхойлъё: b_1 = 1, b_{n+1} - b_n = \begin{cases} 1, & \text{хэрэв } n \text{ нь гурвалжин тоо бол}, \\ 2, & \text{хэрэв } n \text{ нь гурвалжин тоо биш бол}. \end{cases} \tag{1} Тэгвэл \{a_n\}-ийн бүтэц болон математикийн индукцээс a_n = b_n гэдэг нь мөрдөн гарна.
Цаашилбал, (1)-ийг хангах \{b_n\} дараалал цор ганц тул (n = 1 үед 2n - \left[\frac{1 + \sqrt{8n - 7}}{2}\right] = 1 гэдгийг тооцвол) c_n = \begin{cases} 1, & \text{хэрэв } n \text{ нь гурвалжин тоо бол}, \\ 2, & \text{хэрэв } n \text{ нь гурвалжин тоо биш бол} \end{cases} \tag{2} гэдгийг батлахад хангалттай. Энд: c_n = 2(n + 1) - \left[\frac{1 + \sqrt{8(n + 1) - 7}}{2}\right] - \left(2n - \left[\frac{1 + \sqrt{8n - 7}}{2}\right]\right). Үүний тулд зөвхөн n нь гурвалжин тоо байх үед л \frac{1 + \sqrt{8(n + 1) - 7}}{2} \in \mathbf{N}^* \tag{3} болно гэдгийг баталъя.
Үнэхээр, хэрэв n = 1 + 2 + \dots + k = \frac{k(k + 1)}{2} байх k \in \mathbf{N}^* оршдог бол: \begin{aligned} \frac{1 + \sqrt{8(n + 1) - 7}}{2} &= \frac{1 + \sqrt{4k(k + 1) + 1}}{2} \\ &= \frac{1 + 2k + 1}{2} = k + 1 \in \mathbf{N}^*. \end{aligned} Нөгөө талаас хэрэв n нь гурвалжин тоо биш бол \frac{k(k + 1)}{2} < n < \frac{(k + 1)(k + 2)}{2} байх k \in \mathbf{N}^* оршино (өөрөөр хэлбэл, n нь дараалсан хоёр гурвалжин тооны хооронд оршино). Ижил аргаар тооцоолбол: k + 1 < \frac{1 + \sqrt{8(n + 1) - 7}}{2} < k + 2 болно. Иймд (3) биелнэ.

Одоо (2) биелэхийг баталъя. c_n = 2 + \left[\frac{1 + \sqrt{8n - 7}}{2}\right] - \left[\frac{1 + \sqrt{8(n + 1) - 7}}{2}\right] тул n \in \mathbf{N}^* үед: \begin{aligned} 0 &< \frac{1 + \sqrt{8(n + 1) - 7}}{2} - \frac{1 + \sqrt{8n - 7}}{2} \\ &= \frac{1}{2}\left(\sqrt{8n + 1} - \sqrt{8n - 7}\right) \\ &= \frac{1}{2} \cdot \frac{8n + 1 - (8n - 7)}{\sqrt{8n + 1} + \sqrt{8n - 7}} = \frac{4}{\sqrt{8n + 1} + \sqrt{8n - 7}} \\ &\leqslant \frac{4}{\sqrt{8 + 1} + \sqrt{8 - 7}} = 1. \end{aligned} Тиймээс зөвхөн \frac{1 + \sqrt{8(n + 1) - 7}}{2} \in \mathbf{N}^* үед л c_n = 2 - 1 = 1, харин бусад n-ийн хувьд c_n = 2 - 0 = 2 байна.
(3)-аас (2) биелэх нь мөрдөн гарна.
Дүгнэж хэлбэл, a_n = 2n - \left[\frac{1 + \sqrt{8n - 7}}{2}\right].

Тайлбар. Энэ бол бүлэглэгдсэн дарааллын ерөнхий гишүүний томьёог олох бодлого юм. (1) томьёо нь дараалсан гишүүдийн хоорондын хамаарлыг харуулж байна. Хариу нь урьдчилан мэдэгдэж байгаа үед хамаарлыг батлахад бидний энд ашигласан арга нь тусгай арга юм. Дарааллын ерөнхий гишүүний томьёог бие даан олохыг шаардсан тохиолдолд бодлого бүр ч хүнд болдог.

NoteЖишээ 6

Төгсгөлөг a_0, a_1, \dots, a_n дарааллыг хэрэв a_0 + a_k + a_{2k} + \dots = a_1 + a_{k+1} + a_{2k+1} + \dots = \dots = a_{k-1} + a_{2k-1} + a_{3k-1} + \dots биелдэг бол k-тэнцвэртэй гэж нэрлэе.
a_0, a_1, \dots, a_{49} дараалал нь k = 3, 5, 7, 11, 13, 17 хувьд k-тэнцвэртэй болох нь өгөгджээ. Тэгвэл a_0 = a_1 = \dots = a_{49} = 0 болохыг батал.

Баталгаа. Дараах олон гишүүнтийг авч үзье: f(x) = a_0 + a_1 x + \dots + a_{49} x^{49}. \tag{1} Гол санаа нь f(x) олон гишүүнт 50 ялгаатай комплекс язгууртай гэдгийг батлах бөгөөд тэгвэл f(x) нь тэг олон гишүүнт болж a_0 = \dots = a_{49} = 0 гарна.

k \in \{3, 5, 7, 11, 13, 17\} хувьд \varepsilon (\varepsilon \neq 1) нь нэгжээс авсан k-р зэргийн язгуур байг. Тэгвэл m \equiv n \pmod{k} үед \varepsilon^m = \varepsilon^n байна. Иймд: \begin{aligned} f(\varepsilon) &= (a_0 + a_k + a_{2k} + \dots) + (a_1 + a_{k+1} + \dots)\varepsilon + \dots + (a_{k-1} + a_{2k-1} + \dots)\varepsilon^{k-1} \\ &= (a_0 + a_k + a_{2k} + \dots)(1 + \varepsilon + \varepsilon^2 + \dots + \varepsilon^{k-1}) \\ &= 0. \end{aligned} Энд бид бодлогын нөхцөлийн тэнцэтгэл болон \varepsilon нь 1 + x + \dots + x^{k-1} олон гишүүнтийн язгуур гэдгийг ашиглалаа.

Тиймээс k \in \{3, 5, 7, 11, 13, 17\} болон \varepsilon = \mathrm{e}^{\mathrm{i}\frac{2m\pi}{k}} (1 \leqslant m \leqslant k - 1) хувьд \varepsilon нь (1)-ийн комплекс язгуур болно. k нь ялгаатай анхны тоонуудын утгыг авах тул бидэнд ялгаатай комплекс язгуурууд олдоно. Иймд f(x) олон гишүүнт (3 - 1) + (5 - 1) + \dots + (17 - 1) = 50 ширхэг язгууртай болж, тэг олон гишүүнт байх ёстой.
