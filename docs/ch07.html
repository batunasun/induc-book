7. Рекуррент дараалал

Хэрэв \{a_n\} дарааллын n-р гишүүн a_n нь өмнөх хэд хэдэн гишүүнээрээ тодорхойлогддог бол уг дарааллыг рекуррент дараалал гэнэ. Үнэн хэрэгтээ арифметик прогресс ба геометр прогресс нь рекуррент дарааллууд бөгөөд тэдгээрийн рекуррент хамаарал нь харгалзан a_n = 2a_{n-1} - a_{n-2} ба a_n = a_{n-1} \cdot q юм.

Ерөнхий тохиолдолд a_{n+k} = F(a_n, a_{n+1}, \dots, a_{n+k-1}) \tag{1} гэж үзье. Өөрөөр хэлбэл, a_{n+k} нь a_n, a_{n+1}, \dots, a_{n+k-1}-ийн функц бөгөөд анхны нөхцөл a_1, \dots, a_k өгөгдсөн байг. Тэгвэл \{a_n\} дарааллыг k-р эрэмбийн рекуррент дараалал, харин (1)-ийг \{a_n\}-ийн рекуррент хамаарал гэнэ.

Рекуррент дараалалтай холбоотой бодлогууд хоёр ангилалд хуваагдана. Нэг нь рекуррент хамаарал өгөгдсөн үед дарааллын ерөнхий гишүүний томьёог (эсвэл бусад шинж чанарыг) олох; нөгөө нь эхлээд рекуррент хамаарлыг байгуулж, улмаар рекуррент санаагаар бодлогын мөн чанарыг тайлах явдал юм.

Одоо зарим туслах үр дүнгүүдийг авч үзье.
Дараах рекуррент хамаарлыг хангах \{a_n\} дарааллыг тогтмол коэффициенттэй нэгэн төрлийн шугаман рекуррент дараалал гэнэ: a_{n+k} = c_1 a_{n+k-1} + c_2 a_{n+k-2} + \dots + c_k a_n, \tag{2} энд c_1, c_2, \dots, c_k нь тогтмолууд.
Хэрэв \lambda нь \lambda^k = c_1 \lambda^{k-1} + c_2 \lambda^{k-2} + \dots + c_k \tag{3} тэгшитгэлийн язгуур бол \{\lambda^n\} (n = 1, 2, \dots) дараалал (2) рекуррент хамаарлыг хангахыг ажиглая. Цаашилбал, хэрэв (3)-ийн язгуурууд ялгаатай бөгөөд тэдгээрийг \lambda_1, \lambda_2, \dots, \lambda_k гэвэл \{A_1 \lambda_1^n + A_2 \lambda_2^n + \dots + A_k \lambda_k^n\} (n = 1, 2, \dots) дараалал (2)-ыг хангах ба A_1, A_2, \dots, A_k коэффициентүүдийг анхны өгөгдөл a_1, a_2, \dots, a_k-аас (шугаман систем тэгшитгэл бодох замаар) тодорхойлж болно. Ийнхүү бид өгөгдсөн a_1, a_2, \dots, a_k анхны утгатай (2)-ыг хангах дарааллын ерөнхий гишүүнийг олно.

Шугаман рекуррент дарааллын ерөнхий гишүүний томьёог олох энэ аргыг характеристик язгуурын арга, харин (3)-ийг (2)-ийн характеристик тэгшитгэл гэнэ. Хэрэв (3) тэгшитгэл давхардсан язгууртай бол үр дүн нь илүү төвөгтэй болох бөгөөд үүнийг хожмын жишээнүүд дээр харуулах болно.

Үүнтэй харьцуулахад бид үүсгэгч функцийн аргыг мөн ашиглаж чадна. Ерөнхий тохиолдолд \{a_n\} (n = 0, 1, 2, \dots) дарааллын хувьд дараах формаль цувааг \{a_n\} дарааллын үүсгэгч функц гэнэ: f(x) = a_0 + a_1 x + a_2 x^2 + \dots Жишээлбэл, a_n = 1 (n = 0, 1, 2, \dots) тогтмол дарааллын үүсгэгч функц нь төгсгөлгүй буурах геометр прогрессийн нийлбэрийн томьёо ёсоор f(x) = 1 + x + x^2 + \dots = \frac{1}{1 - x} (|x| < 1) байна.

Үүсгэгч функцийн арга нь цувааны нийлэлт зэрэг дээд математикийн мэдлэг шаарддаг тул бид формаль цувааны дараах томьёог баталгаагүйгээр өгч, жишээнүүд дээр хэрхэн хэрэглэхийг харуулъя:
\alpha \in \mathbf{R} хувьд \binom{\alpha}{n} = \frac{\alpha(\alpha - 1)\cdots(\alpha - n + 1)}{n!} (n \in \mathbf{N}^*) гэж тэмдэглэе (энэ нь өмнөх параграфт дурдсан биномын коэффициентийн өргөтгөл бөгөөд мөн \binom{\alpha}{0} = 1 гэж тодорхойлно). Тэгвэл: (1 + x)^\alpha = 1 + \binom{\alpha}{1}x + \binom{\alpha}{2}x^2 + \dots \tag{4} Тухайлбал, \alpha \in \mathbf{N}^* үед (4) нь Ньютоны биномын томьёо болно.

Бусад хэлбэрийн рекуррент дарааллуудыг бодох нэгдсэн арга байхгүй. Түгээмэл хэрэглэгддэг аргуудын нэг нь үл хөдлөх цэгийн арга юм.

NoteЖишээ 1

a_1 = 0, a_{n+1} = 5a_n + \sqrt{24a_n^2 + 1} (n = 1, 2, \dots) нөхцөлийг хангах \{a_n\} дарааллын ерөнхий гишүүний томьёог ол.

Бодолт. Рекуррент хамаарлыг хувиргавал: (a_{n+1} - 5a_n)^2 = 24a_n^2 + 1. Эквивалентээр: a_{n+1}^2 - 10 a_n a_{n+1} + a_n^2 = 1. \tag{1} n-ийн оронд n + 1-ийг орлуулбал: a_{n+2}^2 - 10 a_{n+1} a_{n+2} + a_{n+1}^2 = 1. \tag{2} (1) ба (2)-ыг харьцуулбал a_n ба a_{n+2} нь x^2 - 10 a_{n+1} x + a_{n+1}^2 - 1 = 0 \tag{3} тэгшитгэлийн язгуурууд болохыг харж болно.
Рекуррент хамаарлаас \{a_n\} нь өсөх дараалал гэдэг нь илэрхий. Иймд a_n ба a_{n+2} ялгаатай. Тиймээс (3) тэгшитгэлд Виетийн теоремыг хэрэглэвэл a_{n+2} + a_n = 10 a_{n+1}, өөрөөр хэлбэл a_{n+2} = 10 a_{n+1} - a_n, \quad n = 1, 2, \dots болно. Энэ нь үндсэндээ хоёрдугаар эрэмбийн нэгэн төрлийн шугаман рекуррент дарааллын бодлого юм. Ерөнхий гишүүний томьёог олох дараах хоёр аргыг толилуулъя.

Арга 1. Характеристик тэгшитгэл нь: \lambda^2 = 10\lambda - 1, үүний хоёр язгуур нь \lambda_{1,2} = 5 \pm 2\sqrt{6}. Иймд a_n = A \cdot (5 + 2\sqrt{6})^n + B \cdot (5 - 2\sqrt{6})^n гэж тавьж болно.
a_1 = 0 анхны нөхцөлийг тооцвол a_2 = 1 гарна. Тэгвэл \begin{cases} (5 + 2\sqrt{6})A + (5 - 2\sqrt{6})B = 0, \\ (5 + 2\sqrt{6})^2 A + (5 - 2\sqrt{6})^2 B = 1 \end{cases} системийг бодвол A = \frac{5 - 2\sqrt{6}}{4\sqrt{6}}, B = \frac{-5 - 2\sqrt{6}}{4\sqrt{6}} болно. Тиймээс: a_n = \frac{1}{4\sqrt{6}}\left((5 + 2\sqrt{6})^{n-1} - (5 - 2\sqrt{6})^{n-1}\right).

Арга 2. Үүсгэгч функцийн аргыг хэрэглэе. Тооцоог хялбар болгохын тулд рекуррент хамаарал болон a_1 = 0, a_2 = 1 нөхцөлөөс a_0 = -1 гэж нэмж тодорхойлъё. Тэгвэл \{a_n\} (n = 0, 1, 2, \dots) дарааллын үүсгэгч функц нь: \begin{aligned} f(x) = \sum_{n=0}^{+\infty} a_n x^n &= -1 + \sum_{n=2}^{+\infty} a_n x^n \\ &= -1 + 10\sum_{n=2}^{+\infty} a_{n-1} x^n - \sum_{n=2}^{+\infty} a_{n-2} x^n \\ &= -1 + 10x\sum_{n=1}^{+\infty} a_n x^n - x^2\sum_{n=0}^{+\infty} a_n x^n \\ &= -1 + 10x(f(x) + 1) - x^2 f(x). \end{aligned} Энэ тэгшитгэлийг бодвол f(x) = \frac{10x - 1}{x^2 - 10x + 1} гарна.
f(x) = \frac{A}{1 - (5 + 2\sqrt{6})x} + \frac{B}{1 - (5 - 2\sqrt{6})x} хэлбэрт (энгийн бутархайн нийлбэрт) задалбал: \begin{cases} (5 - 2\sqrt{6})A + (5 + 2\sqrt{6})B = -10, \\ A + B = -1. \end{cases} Эндээс B = \frac{1}{4\sqrt{6}}(-5 - 2\sqrt{6}), A = \frac{1}{4\sqrt{6}}(5 - 2\sqrt{6}) болно.
Одоо f(x)-ийг формаль цуваанд задалбал: \begin{aligned} f(x) &= A\sum_{n=0}^{+\infty} (5 + 2\sqrt{6})^n x^n + B\sum_{n=0}^{+\infty} (5 - 2\sqrt{6})^n x^n \\ &= \sum_{n=0}^{+\infty} \left(A(5 + 2\sqrt{6})^n + B(5 - 2\sqrt{6})^n\right)x^n. \end{aligned} Иймд: \begin{aligned} a_n &= A(5 + 2\sqrt{6})^n + B(5 - 2\sqrt{6})^n \\ &= \frac{1}{4\sqrt{6}}\left((5 + 2\sqrt{6})^{n-1} - (5 - 2\sqrt{6})^{n-1}\right). \end{aligned}

Тайлбар. Энэ жишээ нь үүсгэгч функцийн аргаар дарааллын ерөнхий гишүүний томьёог олох үндсэн алхмуудыг харуулж байна: эхлээд рекуррент хамаарлаас үүсгэгч функц f(x)-ийг олно, дараа нь f(x)-ийг формаль цуваанд задалж, харгалзах гишүүдийн коэффициентүүдийг тэнцүүлэх замаар ерөнхий гишүүний томьёог гаргаж авна.

NoteЖишээ 2

\{a_n\} дараалал нь a_1 = 2 бөгөөд n = 1, 2, \dots хувьд a_{n+1} = \frac{a_n}{2} + \frac{1}{a_n} \tag{1} нөхцөлийг хангадаг бол дарааллын ерөнхий гишүүний томьёог ол.

Бодолт. Энд бид үл хөдлөх цэгийн аргыг (энэ нь функцийн итерацийн санаанаас үүдэлтэй) танилцуулъя. Эхлээд \lambda = \frac{\lambda}{2} + \frac{1}{\lambda} \tag{2} тэгшитгэлийн язгууруудыг олъё. Тэдгээр нь \lambda_{1,2} = \pm\sqrt{2} байна.
(1) болон a_1 = 2 гэдгээс \{a_n\}-ийн гишүүн бүр эерэг рационал тоо болохыг харж болно. Одоо (1) - (2)-оос \lambda = \pm\sqrt{2} үед a_{n+1} - \lambda = \frac{a_n - \lambda}{2} + \left(\frac{1}{a_n} - \frac{1}{\lambda}\right) биелэх ба үүнийг хувиргавал: \frac{a_{n+1} - \lambda}{a_n - \lambda} = \frac{1}{2} - \frac{1}{\lambda a_n} = \frac{\lambda a_n - 2}{2\lambda a_n}. \tag{3} (3)-т \lambda-гийн оронд харгалзан \sqrt{2} ба -\sqrt{2}-ыг орлуулаад хоёр тэгшитгэлийн хоёр талыг харгалзуулан хуваавал: \frac{a_{n+1} - \sqrt{2}}{a_{n+1} + \sqrt{2}} = \left(\frac{a_n - \sqrt{2}}{a_n + \sqrt{2}}\right)^2. Иймд: \begin{aligned} \frac{a_{n+1} - \sqrt{2}}{a_{n+1} + \sqrt{2}} &= \left(\frac{a_n - \sqrt{2}}{a_n + \sqrt{2}}\right)^2 = \left(\frac{a_{n-1} - \sqrt{2}}{a_{n-1} + \sqrt{2}}\right)^{2^2} \\ &= \dots = \left(\frac{a_1 - \sqrt{2}}{a_1 + \sqrt{2}}\right)^{2^n} = (3 - 2\sqrt{2})^{2^n} \\ &= (\sqrt{2} - 1)^{2^{n+1}}. \end{aligned} Тиймээс \frac{a_n - \sqrt{2}}{a_n + \sqrt{2}} = (\sqrt{2} - 1)^{2^n} болно. Энэ тэгшитгэлийг a_n-ийн хувьд бодвол: a_n = \frac{\sqrt{2}\left(1 + (\sqrt{2} - 1)^{2^n}\right)}{1 - (\sqrt{2} - 1)^{2^n}}.

NoteЖишээ 3

m, n \in \mathbf{N}^* бөгөөд mn нь гурвалжин тоо байг (өөрөөр хэлбэл, mn = 1 + 2 + \dots + t байх t \in \mathbf{N}^* оршино). a_1 = m, \quad a_2 = n, \quad a_j = 6a_{j-1} - a_{j-2} + k, \quad j = 3, 4, \dots рекуррент хамаарлаар тодорхойлогдох \{a_n\} дарааллын дурын j дугаарын хувьд a_j a_{j+1} нь гурвалжин тоо байхаар эерэг бүхэл k тоо оршихыг батал.

Баталгаа. Дараах эквивалент шилжилтүүдийг ажиглая: \begin{aligned} x \text{ нь гурвалжин тоо} &\iff x = 1 + 2 + \dots + t \text{ байх } t \in \mathbf{N}^* \text{ оршино} \\ &\iff x = \frac{t(t + 1)}{2} \text{ байх } t \in \mathbf{N}^* \text{ оршино} \\ &\iff 8x + 1 = (2t + 1)^2 \text{ байх } t \in \mathbf{N}^* \text{ оршино}. \end{aligned} Иймд бид зөвхөн аливаа j \in \mathbf{N}^* хувьд 8a_j a_{j+1} + 1 нь бүтэн квадрат байх k \in \mathbf{N}^* оршино гэдгийг батлахад хангалттай.

Бүтэн квадратын томьёоноос эхлэн дурын j \in \mathbf{N}^* хувьд 8a_j a_{j+1} + 1 = (a_j + a_{j+1} + l)^2 \tag{1} биелэх k \in \mathbf{N}^* орших эсэхийг шалгая (энд l нь зөвхөн k-аас хамаарах тогтмол).
Энэ таамаглалд j = 1 гэж авбал l = \sqrt{8mn + 1} - m - n болно (mn нь гурвалжин тоо тул \sqrt{8mn + 1} \in \mathbf{N}^*).
Цаашилбал, хэрэв дурын j \in \mathbf{N}^* хувьд (1) биелдэг бол (1)-д j-ийн оронд j + 1-ийг орлуулбал: 8a_{j+1} a_{j+2} + 1 = (a_{j+1} + a_{j+2} + l)^2. \tag{2} Энэ хоёр тэгшитгэлийн хоёр талыг харгалзуулан хасвал: \begin{aligned} 8(a_{j+2} - a_j)a_{j+1} &= (a_{j+2} - a_j)(a_{j+2} + 2a_{j+1} + a_j + 2l) \\ \iff 8a_{j+1} &= a_{j+2} + 2a_{j+1} + a_j + 2l \\ \iff a_{j+2} &= 6a_{j+1} - a_j - 2l. \tag{3} \end{aligned} Тэгвэл (1) ба (3)-аас (2) биелэх нь мөрдөн гарна.
Дээрх шинжилгээнээс үзвэл хэрэв бид k = -2l = 2(m + n) - 2\sqrt{8mn + 1} гэж авбал өгөгдсөн рекуррент томьёогоор тодорхойлогдох \{a_n\} дараалал бодлогын нөхцөлийг хангах бөгөөд үүнийг математикийн индукцээр хялбархан баталж болно.
Дүгнэж хэлбэл, өгүүлбэр үнэн.

Тайлбар. Бид энд «таамагласны дараа батлах» санааг хэрэглэсэн бөгөөд энэ нь зөвхөн дарааллын бодлогод бус математикийн судалгаанд бүхэлд нь түгээмэл тохиолддог онгод мэдрэмжийн тусгал юм.

NoteЖишээ 4

0, 1, 3, 0, 4, 9, 3, 10, \dots дараалал дараах байдлаар тодорхойлогдов: a_0 = 0 бөгөөд n = 1, 2, \dots хувьд a_n = \begin{cases} a_{n-1} - n, & \text{хэрэв } a_{n-1} \geqslant n \text{ бол}, \\ a_{n-1} + n, & \text{бусад тохиолдолд}. \end{cases} Энэ дараалалд сөрөг биш бүхэл тоо бүр тааралдах уу? Хариултаа батал.

Бодолт. Сөрөг биш бүхэл тоо бүр энэ дараалалд тааралдана.
Тодорхойлолт ёсоор \{a_n\} нь бүхэл тоон дараалал тул эхлээд \{a_n\}-ийн гишүүн бүрийн утгын мужийг тогтооё. n-ээр индукцлэн 0 \leqslant a_n \leqslant 2n - 1 \quad (n \geqslant 1) \tag{1} болохыг баталъя.

n = 1 үед бодлогын нөхцөлөөс a_1 = 1 тул (1) биелнэ. a_{n-1} (n \geqslant 2) нь (1)-ийг хангана гэж таамаглая. n \leqslant a_{n-1} \leqslant 2n - 3 үед a_n = a_{n-1} - n \in [0, n - 3] болох ба (n \leqslant 2n - 3 гэдгээс n \geqslant 3) энэ нь (1)-ийг хангана; харин 0 \leqslant a_{n-1} \leqslant n - 1 үед a_n = a_{n-1} + n \in [n, 2n - 1] болох бөгөөд мөн (1)-ийг хангана. Иймд бүх n \in \mathbf{N}^* хувьд (1) биелнэ.

Одоо a_n-ийн рекуррент томьёог дахин бичье: a_{n-1} = 0 үед a_n = n, a_{n+1} = 2n + 1; a_{n-1} \in [1, n - 1] үед a_n = n + a_{n-1} \in [n + 1, 2n - 1] ба улмаар a_{n+1} = a_n - (n + 1) = a_{n-1} - 1; a_{n-1} \in [n, 2n - 3] үед a_n = a_{n-1} - n \in [0, n - 3] ба улмаар a_{n+1} = a_n + (n + 1) = a_{n-1} + 1. Тиймээс n \geqslant 3 үед: a_{n+1} = \begin{cases} 2n + 1, & \text{хэрэв } a_{n-1} = 0 \text{ бол}, \\ a_{n-1} - 1, & \text{хэрэв } a_{n-1} \in [1, n - 1] \text{ бол}, \\ a_{n-1} + 1, & \text{хэрэв } a_{n-1} \in [n, 2n - 3] \text{ бол}. \end{cases} \tag{2}

Үндсэн асуултдаа эргэн оръё: хэрэв дараалалд тааралдахгүй сөрөг биш бүхэл тоонууд байдаг бол тэдгээрийн хамгийн багыг нь авъя. Түүнийг M гэвэл M > 1 болох ба M - 1 нь дараалалд тааралдана. a_{n-1} = M - 1 байг. Хэрэв a_{n-1} \in [n, 2n - 3] бол M = a_{n-1} + 1 = a_{n+1} болж зөрчил үүснэ. Иймд a_{n-1} \leqslant n - 1. M > 1 тул a_{n-1} \in [1, n - 1] болох ба a_{n+1} = a_{n-1} - 1 \in [0, n - 2]. Цаашилбал a_{n+3} = a_{n+1} - 1 (эсвэл a_{n+1} = 0). Энэ үйлдлийг дахин дахин давтахад a_{n-1} > a_{n+1} > a_{n+3} > \dots > a_{s-1} = 0 (s \geqslant n + 2) дэд дараалал үүснэ.
a_{n-1} \leqslant n - 1 тул M \leqslant n байна. a_{s-1} = 0 гэдгээс (2) ёсоор a_{s+1} = 2s + 1 > s + 2 гэж гарна. Цаашилбал: a_{s+2} = a_{s+1} - (s + 2) = s - 1 \in [0, s + 1]. Үүнтэй ижил аргаар a_{s+4} \in \{0, a_{s+2} - 1\}, \dots гэж гарна. Тиймээс a_t = M байх t дугаар заавал олдоно (учир нь s - 1 \geqslant n + 1 \geqslant M). Иймд M нь \{a_n\} дарааллын гишүүн болж зөрчил үүснэ.
Дүгнэж хэлбэл, сөрөг биш бүхэл тоо бүр \{a_n\} дараалалд тааралдана.

Тайлбар. Энэ бодлогыг бодох түлхүүр нь өгөгдсөн рекуррент томьёог (2) хэлбэрт зохистой хувиргаж бичих явдал бөгөөд энэ нь хоёр гишүүн тутамд 1-ээр нэмэгдэх эсвэл 1-ээр хорогдох зүй тогтлыг илрүүлж өгсөн. Энэ нь сөрөг биш бүхэл тоо бүр дараалалд оршино гэдгийг батлах бат суурь боллоо.

NoteЖишээ 5

a, b, c үсгүүдээс тогтох бөгөөд a болон b үсгүүд дараалан ороогүй n урттай үгсийн олонлогийг A_n гэе; харин a, b, c үсгүүдээс тогтох бөгөөд дараалсан гурван ялгаатай үсэг ороогүй n урттай үгсийн олонлогийг B_n гэе. Аливаа эерэг бүхэл n тооны хувьд |B_{n+1}| = 3|A_n| биелэхийг батал.

Баталгаа. Энэ бодлогыг рекуррент аргаар бодъё.
A_n олонлог дахь c үсгээр эхэлсэн үгсийн тоог c_n, харин a эсвэл b үсгээр эхэлсэн үгсийн тоог d_n гэж тэмдэглэе.
A_{n+1} дэх үгсийг эхний үсгээр нь ангилъя. Хэрэв эхний үсэг нь c бол эхний үсгийг хасахад үлдэх үг A_n-д харьяалагдана; хэрэв эхний үсэг нь a бол хоёр дахь үсэг нь заавал c эсвэл b байна; хэрэв эхний үсэг нь b бол хоёр дахь үсэг нь заавал c эсвэл a байна. Тиймээс дараах рекуррент томьёо биелнэ: \begin{cases} c_{n+1} = |A_n| = c_n + d_n, \\ d_{n+1} = 2c_n + d_n. \tag{1} \end{cases}

Одоо B_n олонлог дахь эхний хоёр үсэг нь ижил үгсийн тоог c'_n, эхний хоёр үсэг нь ялгаатай үгсийн тоог d'_n гэе.
B_{n+1} дэх үгсийг эхний хоёр үсгээр нь ангилъя. Хэрэв эхний хоёр үсэг нь ижил бол гурав дахь үсгийг дураараа сонгож болох ба эхний үсгийг хасахад үлдэх үг B_n-д харьяалагдана. Хэрэв эхний хоёр үсэг нь ялгаатай бол гурав дахь үсэг нь эхний хоёр үсгийн аль нэгтэй заавал ижил байх ёстой. Хэрэв эхний үсэгтэй ижил бол эхний үсгийг хасахад d'_n ширхэг үг үүснэ. Хэрэв хоёр дахь үсэгтэй ижил бол эхний үсгийг хасахад 2c'_n ширхэг үг үүснэ (жишээ нь, abb\dots ба cbb\dots үгсийн эхний үсгийг хасахад ижил үг үүсдэг тул коэффициент нь 2 байна). Тиймээс рекуррент томьёо нь: \begin{cases} c'_{n+1} = |B_n| = c'_n + d'_n, \\ d'_{n+1} = 2c'_n + d'_n. \tag{2} \end{cases}

(1) ба (2) рекуррент томьёонууд яг ижил бөгөөд зөвхөн анхны утгаараа л ялгаатай гэдгийг ажиглая. Шууд тоолбол c_1 = 1, d_1 = 2; c'_2 = 3, d'_2 = 6 тул c'_2 = 3c_1, d'_2 = 3d_1 байна. Рекуррент томьёоноос c'_{n+1} = 3c_n, d'_{n+1} = 3d_n гэж гарна. |A_n| = c_{n+1} ба |B_n| = c'_{n+1} гэдгийг тооцвол |B_{n+1}| = 3|A_n| болно.
Өгүүлбэр батлагдлаа.

Тайлбар. Комбинаторик болон тоолох бодлогод рекуррент санааг хэрэглэх нь чухал арга юм. Бидний энд байгуулсан рекуррент томьёог тогтмол коэффициенттэй нэгэн төрлийн шугаман рекуррент хамаарал руу шилжүүлж, улмаар |A_n|-ийн утгыг ч олж чадна.
