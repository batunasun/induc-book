14. Батлахаасаа өмнө таамаглал дэвшүүлэх

Батлахаасаа өмнө таамаглал дэвшүүлэх нь математикийн нээлтийн үндсэн үйл явц юм. Хэрэв таамагласан өгүүлбэрийг баталж чадахгүй бол тэр нь математикийн таамаглал (гипотез) болж үлдэнэ. Эерэг бүхэл n тооноос хамаарсан өгүүлбэрийг эхлээд жижиг жишээнүүд дээр туршин шалгаж, улмаар аналоги болон гүйцэд бус индукц зэрэг аргыг ашиглан ерөнхий дүгнэлтийг таамаглаад, түүнийгээ математикийн индукцээр батлахыг оролддог. Ийм үйл явц бидний бодлого бодох туршлагад олонтоо тохиолддог.

NoteЖишээ 1

f: \mathbf{N}^* \to \mathbf{N} функц нь f(1) = 0 бөгөөд аливаа n \in \mathbf{N}^* (n \geqslant 2) хувьд f(n) = \max\left\{ f(j) + f(n - j) + j \;\middle|\; j = 1, 2, \dots, \left[\frac{n}{2}\right] \right\} томьёогоор тодорхойлогдов. f(2004)-ийн утгыг олж, зөв болохыг нь батал.

Бодолт. n-ийн бага утгууд дээр f(n)-ийн утгыг тооцоолж үзвэл: f(2) = 1, f(3) = 2, f(4) = 4, f(5) = 5, \dots гарна. Эдгээр утгыг тооцоолох явцад 1 \leqslant j \leqslant \left[\frac{n}{2}\right] үед f(j) + f(n - j) + j илэрхийллийн хамгийн их утга нь j = \left[\frac{n}{2}\right] цэг дээр хүрч байгааг ажиглаж болно. Тиймээс дараах таамаглалыг дэвшүүлье: f(2n) = 2f(n) + n, \quad f(2n + 1) = f(n) + f(n + 1) + n. \tag{1}

Дараа нь математикийн индукц ашиглан (1) үнэн болохыг баталъя.
n = 1 үед дээрх тооцооноос (1) үнэн болохыг мэднэ.
Одоо 1, 2, \dots, n - 1 хувьд (1) үнэн гэж таамаглаад n тохиолдлыг авч үзье.
Эхлээд f(2n)-ийн утгыг олъё: \begin{aligned} f(2n) &= \max\{f(j) + f(2n - j) + j \mid 1 \leqslant j \leqslant n\} \\ &\geqslant f(n) + f(2n - n) + n \\ &= 2f(n) + n. \end{aligned} Иймд бид зөвхөн f(2n) \leqslant 2f(n) + n гэдгийг батлахад хангалттай.
1 \leqslant j \leqslant n тохиолдлуудыг j тэгш ба сондгой байх хоёр хэсэгт хувааж авч үзье: - j = 2k (1 \leqslant k \leqslant \left[\frac{n}{2}\right]) үед индукцийн таамаглал ёсоор: \begin{aligned} f(j) + f(2n - j) + j &= f(2k) + f(2(n - k)) + 2k \\ &= (2f(k) + k) + (2f(n - k) + n - k) + 2k \\ &= 2(f(k) + f(n - k) + k) + n \leqslant 2f(n) + n. \end{aligned} Сүүлийн тэнцэтгэл бишийг f(n)-ийн тодорхойлолтоос гарган авлаа. - j = 2k - 1 (1 \leqslant k \leqslant \left[\frac{n + 1}{2}\right]) үед индукцийн таамаглал ёсоор: \begin{aligned} f(j) + f(2n - j) + j &= f(2k - 1) + f(2(n - k) + 1) + 2k - 1 \\ &= (f(k) + f(k - 1) + k - 1) + (f(n - k) + f(n - k + 1) + n - k) + 2k - 1 \\ &= (f(k - 1) + f(n - (k - 1)) + k - 1) + (f(k) + f(n - k) + k) + n - 1 \\ &\leqslant f(n) + f(n) + n = 2f(n) + n. \end{aligned} Энд бид f(0) = 0 гэж үзлээ. n тэгш үед \left[\frac{n + 1}{2}\right] = \left[\frac{n}{2}\right]; n сондгой үед n = 2m + 1 гэвэл k = \left[\frac{n + 1}{2}\right] үед f(k) + f(n - k) + k = f(m + 1) + f(m) + m + 1 \leqslant f(n) + 1 тул дээрх тэнцэтгэл бишийн гаргалгаа зөв. Тиймээс f(2n) \leqslant 2f(n) + n.

f(2n + 1)-ийг үнэлэх үед дээрхтэй ижил шинжилгээ хийвэл бид зөвхөн f(2n + 1) \leqslant f(n) + f(n + 1) + n гэдгийг батлахад хангалттай.
Үүнтэй адилаар 1 \leqslant j \leqslant n тохиолдлуудыг j тэгш ба сондгой үед хувааж авч үзье: - j = 2k (1 \leqslant k \leqslant \left[\frac{n}{2}\right]) үед индукцийн таамаглал ёсоор: \begin{aligned} f(j) + f(2n + 1 - j) + j &= f(2k) + f(2n + 1 - 2k) + 2k \\ &= (2f(k) + k) + (f(n - k) + f(n - k + 1) + n - k) + 2k \\ &= (f(k) + f(n - k) + k) + (f(k) + f(n + 1 - k) + k) + n \\ &\leqslant f(n) + f(n + 1) + n. \end{aligned} - j = 2k - 1 (1 \leqslant k \leqslant \left[\frac{n + 1}{2}\right]) үед: \begin{aligned} f(j) + f(2n + 1 - j) + j &= f(2k - 1) + f(2n - 2k + 2) + 2k - 1 \\ &= (f(k - 1) + f(k) + k - 1) + (2f(n - k + 1) + n - k + 1) + 2k - 1 \\ &= (f(k - 1) + f(n - (k - 1)) + k - 1) + (f(k) + f(n + 1 - k) + k) + n \\ &\leqslant f(n) + f(n + 1) + n. \end{aligned} Тиймээс f(2n + 1) \leqslant f(n) + f(n + 1) + n.
Дээрхийг нэгтгэвэл аливаа n \in \mathbf{N}^* хувьд (1) ямагт үнэн.
Одоо (1)-ийг ашиглан ээлж дараалан рекуррентээр тооцоолбол: \begin{aligned} &f(2) = 1, \; f(3) = 2, \; f(4) = 4, \; f(7) = 9, \; f(8) = 12, \; f(15) = 28, \\ &f(16) = 32, \; f(31) = 75, \; f(32) = 80, \; f(62) = 181, \; f(63) = 186, \\ &f(125) = 429, \; f(126) = 435, \; f(250) = 983, \; f(251) = 989, \; f(501) = 2222, \\ &f(1002) = 4945, \; f(2004) = 10\,892. \end{aligned} Иймд хайж буй утга нь f(2004) = 10\,892 байна.

Тайлбар. Бид таамаглал дэвшүүлэх үед тийм ч нягт нямбай биш байж болно. Харин гаргалгаа, баталгаа хийх үедээ туйлын болгоомжтой байх ёстой; эс тэгвээс буруу дүгнэлтэд хүрэх нь амархан бөгөөд энэ нь шинжлэх ухааны хандлага, зуршилд хортой юм.

NoteЖишээ 2

Эерэг бүхэл k \geqslant 1 тооны хувьд k-д хуваагддаггүй хамгийн бага анхны тоог p(k) гэе. Хэрэв p(k) > 2 бол p(k)-ээс бага бүх анхны тооны үржвэрийг q(k) гэж тэмдэглэе. Хэрэв p(k) = 2 бол q(k) = 1 гэе.
\{x_n\} дарааллыг дараах байдлаар тодорхойлъё: x_0 = 1 ба x_{n+1} = \frac{x_n p(x_n)}{q(x_n)}, \quad n = 0, 1, 2, \dots x_n = 111\,111 байх бүх n \in \mathbf{N}^* тоог ол.

Бодолт. x_n-ийн эхний хэдэн утгыг тооцоолж үзье.
Хэрэв бид n-ийг хоёртын тооллын системд бичвэл дээрх өгөгдлүүдээс n-ийн хоёртын бичлэг дэх 1-үүдийн тоо нь x_n-ийг бүрдүүлж буй анхны тоон үржигдэхүүнүүдийн тоотой тэнцүү болохыг харж болно. Цаашлаад анхны тоонуудыг багаас их рүү нь p_0 < p_1 < p_2 < \dots гэж эрэмбэлбэл дараах таамаглалд хүрэхэд хэцүү биш:
Аливаа n \in \mathbf{N}^* хувьд хоёртын тооллын системд n = 2^{r_1} + 2^{r_2} + \dots + 2^{r_k}, \quad r_1 > r_2 > \dots > r_k \geqslant 0 гэж бичвэл (өөрөөр хэлбэл, n-д харгалзах хоёртын тоо нийт r_1 + 1 оронтой бөгөөд r_k + 1, r_{k-1} + 1, \dots, r_1 + 1 дүгээр оронгууд дээр 1, бусад оронгууд дээр 0 байна) x_n = p_{r_1} p_{r_2} \cdots p_{r_k} байна; энд p_{r_i} нь бүх анхны тооны дотроос (r_i + 1)-р бага анхны тоог илэрхийлнэ. (1)

Дээрх дүгнэлтийг n-ээр индукцлэн баталъя.
n = 1 үед x_1 = 2 = p_0 гэдгээс (1) биелэх нь илэрхий.
n үед өгүүлбэр үнэн, өөрөөр хэлбэл x_n = p_{r_1} p_{r_2} \cdots p_{r_k} гэж таамаглаад n + 1 тохиолдлыг авч үзье: - Хэрэв r_k \geqslant 1 буюу n-ийн хоёртын бичлэгийн сүүлийн цифр 0 бол n + 1 = 2^{r_1} + 2^{r_2} + \dots + 2^{r_k} + 2^0 болно. Энэ үед x_n нь сондгой тоо тул p(x_n) = 2, улмаар q(x_n) = 1 байна. Индукцийн таамаглал ёсоор: x_{n+1} = \frac{x_n p(x_n)}{q(x_n)} = \frac{x_n \cdot p_0}{1} = p_{r_1} \cdots p_{r_k} p_0. - Хэрэв r_k = 0 бол r_{i-1} \geqslant r_i + 2 байх хамгийн их эерэг бүхэл дугаарыг i гэе (өөрөөр хэлбэл, n-д харгалзах хоёртын тооны баруун талаас хоёр дахь цифрээс зүүн тийш тоолоход зүүн талдаа ядаж нэг 0 агуулсан хамгийн эхний орон нь (r_i + 1)-р орон байна). Тэгвэл: n = \underset{\text{$(r_1+1)$-р орон}}{1} 0\cdots 0 \underset{\text{$(r_2+1)$-р орон}}{1} 0\cdots 0 \underset{\text{$(r_{i-1}+1)$-р орон}}{1} 0\cdots 0 \underset{\text{$(r_i+1)$-р орон}}{1} \underbrace{11\cdots 11}_{r_i \text{ ширхэг}}. Энэ үед 0 \leqslant j \leqslant k - i хувьд r_{k-j} = j байна. Тэгвэл n + 1 = 2^{r_1} + 2^{r_2} + \dots + 2^{r_{i-1}} + 2^{r_i + 1} болно (хэрэв ийм i оршихгүй бол n + 1 = 2^{r_1 + 1}). Энэ үед индукцийн таамаглал ёсоор p(x_n) = p_{r_i + 1} болох тул: q(x_n) = p_0 p_1 \cdots p_{r_i} = p_0 p_1 \cdots p_{k-i} = p_{r_k} p_{r_{k-1}} \cdots p_{r_i}. Иймд: x_{n+1} = \frac{x_n \cdot p(x_n)}{q(x_n)} = \frac{p_{r_1} \cdots p_{r_{i-1}} p_{r_i + 1} p_{r_i} \cdots p_{r_k}}{p_{r_i} \cdots p_{r_k}} = p_{r_1} \cdots p_{r_{i-1}} p_{r_i + 1}.

Тиймээс n + 1 үед (1) үнэн, өөрөөр хэлбэл аливаа n \in \mathbf{N}^* хувьд (1) биелнэ.
Одоо 111\,111 = 3 \times 7 \times 11 \times 13 \times 37 = p_1 p_3 p_4 p_5 p_{11} гэдгээс x_n = 111\,111 нөхцөлийг хангах эерэг бүхэл n тооны хоёртын бичлэг нь: n = 2^{11} + 2^5 + 2^4 + 2^3 + 2 = 2106 болно.
Иймд бидний хайж буй тоо нь n = 2106 юм.

NoteЖишээ 3

Бүхэл тоон \{a_n\} дараалал дараах байдлаар тодорхойлогдов: a_1 = 2, \quad a_2 = 7, \quad -\frac{1}{2} < a_{n+1} - \frac{a_n^2}{a_{n-1}} \leqslant \frac{1}{2}, \quad n = 2, 3, \dots \{a_n\} дарааллын ерөнхий гишүүний томьёог ол.

Бодолт. Бодлогод өгөгдсөн рекуррент хамаарлаас a_n-ийг шууд олоход амаргүй. Энэ нөхцөлөөс тогтмол коэффициенттэй шугаман рекуррент томьёо гарган авч чадах болов уу? a_{n+1} = p a_n + q a_{n-1} гэж зоригтой таамаглая (энд p, q нь олох шаардлагатай тогтмолууд).
Эхний хэдэн гишүүнийг тооцоолж үзвэл a_1 = 2, a_2 = 7, a_3 = 25, a_4 = 89, \dots гарна. Эдгээр эхний гишүүдийг ашиглан коэффициентүүдийг олбол n \geqslant 2 хувьд a_{n+1} = 3a_n + 2a_{n-1} гэсэн таамаглалд хүрнэ.

Дараа нь математикийн индукц ашиглан дээрх таамаглалыг баталъя.
n = 2, 3 үед дээрх таамаглал зөв. k \leqslant n хувьд a_{k+1} = 3a_k + 2a_{k-1} биелнэ гэж таамаглая. k = n + 1 тохиолдолд: \frac{a_{n+1}^2}{a_n} = \frac{a_{n+1}(3a_n + 2a_{n-1})}{a_n} = 3a_{n+1} + 2a_n + 2\left(\frac{a_{n+1} a_{n-1} - a_n^2}{a_n}\right). Дараах үнэлгээг ажиглая: \begin{aligned} \left|2\left(\frac{a_{n+1} a_{n-1} - a_n^2}{a_n}\right)\right| &= \left|\frac{2a_{n-1}}{a_n}\right| \left|a_{n+1} - \frac{a_n^2}{a_{n-1}}\right| \\ &\leqslant \frac{1}{2}\left|\frac{2a_{n-1}}{a_n}\right|. \end{aligned} Индукцийн таамаглал ёсоор a_n > 2a_{n-1} гэдгийг мэднэ. Иймд: \left|3a_{n+1} + 2a_n - \frac{a_{n+1}^2}{a_n}\right| < \frac{1}{2}. a_{n+2} нь бүхэл тоо бөгөөд \left|a_{n+2} - \frac{a_{n+1}^2}{a_n}\right| \leqslant \frac{1}{2} тул: \begin{aligned} |a_{n+2} - (3a_{n+1} + 2a_n)| &= \left|a_{n+2} - \frac{a_{n+1}^2}{a_n}\right| + \left|\frac{a_{n+1}^2}{a_n} - (3a_{n+1} + 2a_n)\right| \\ &< \frac{1}{2} + \frac{1}{2} = 1. \end{aligned} Тиймээс a_{n+2} = 3a_{n+1} + 2a_n болно. Ийнхүү таамаглал k = n + 1 үед үнэн.

Дээрхийг нэгтгэвэл \{a_n\} дараалал нь a_1 = 2, a_2 = 7, a_n = 3a_{n-1} + 2a_{n-2} (n = 3, 4, \dots) нөхцөлийг хангана. Рекуррент дарааллын характеристик тэгшитгэлийг ашиглан тогтмол коэффициенттэй шугаман рекуррент томьёог бодвол: a_n = \frac{17 + 5\sqrt{17}}{68}\left(\frac{3 + \sqrt{17}}{2}\right)^n + \frac{17 - 5\sqrt{17}}{68}\left(\frac{3 - \sqrt{17}}{2}\right)^n.

NoteЖишээ 4

f: \mathbf{N}^* \to \mathbf{N}^* функц дараах байдлаар тодорхойлогдов: f(1) = 1 бөгөөд n \in \mathbf{N}^* хувьд f(n + 1) нь a_1 < a_2 < \dots < a_m = n ба f(a_1) = f(a_2) = \dots = f(a_m) нөхцөлүүдийг хангах эерэг бүхэл тоонуудаас тогтох a_1, a_2, \dots, a_m арифметик прогресс орших хамгийн их эерэг бүхэл m тоо юм (энд 3-аас цөөн гишүүнтэй дарааллыг мөн арифметик прогресс гэж үзнэ). Аливаа эерэг бүхэл n тооны хувьд f(4n + 8) = n + 2 биелэхийг батал.

Баталгаа. Бодлогод n бүрийн хувьд функцийн утгыг олохыг шаардаагүй. Гэвч f-ийн тодорхойлолтыг харвал f(n)-ийн өмнөх утга бүрийг олсон үед л дараагийнхыг нь хялбархан олж чадна.
f-ийн тодорхойлолтыг ашиглан эхний утгуудыг тооцоолж үзвэл: \begin{aligned} &f(1) = 1, \; f(2) = 1, \; f(3) = 2, \; f(4) = 1, \; f(5) = 2, \; f(6) = 2, \\ &f(7) = 2, \; f(8) = 3, \; f(9) = 1, \; f(10) = 2, \; f(11) = 2, \; f(12) = 3, \\ &f(13) = 2, \; f(14) = 3, \; f(15) = 2, \; f(16) = 4, \; f(17) = 1, \; f(18) = 3, \\ &f(19) = 2, \; f(20) = 5, \; f(21) = 1, \; f(22) = 2, \; f(23) = 2, \; f(24) = 6, \\ &f(25) = 1, \; f(26) = 4, \; f(27) = 2, \; f(28) = 7, \; f(29) = 1, \; f(30) = 4, \\ &f(31) = 2, \; f(32) = 8, \; f(33) = 1, \; f(34) = 5, \; f(35) = 2, \; f(36) = 9, \; \dots \end{aligned} Эдгээр жагсаасан утгуудаас 1 \leqslant n \leqslant 7 үед f(4n + 8) = n + 2 биелж байгааг харж болно. Цаашилбал, n \geqslant 8 үед \begin{aligned} f(4n + 1) &= 1; \quad f(4n + 2) = n - 3; \\ f(4n + 3) &= 2; \quad f(4n + 4) = n + 1 \tag{1} \end{aligned} биелнэ гэсэн таамаглалд хөтөлнө.

Дараа нь n-ээр индукцлэн n \geqslant 8 үед (1) ямагт үнэн болохыг баталъя.
n = 8 үед дээрх жагсаасан утгуудаас (1) үнэн болохыг мэднэ.
Одоо 8, 9, \dots, n - 1 хувьд (1) үнэн гэж таамаглаад n (n \geqslant 9) тохиолдлыг авч үзье.
f(1)-ээс f(36) хүртэлх тооцоолсон утгууд болон индукцийн таамаглалыг ашиглавал f(1), f(2), \dots, f(4n) тоонуудын дотроос хамгийн их утга нь f(4n) = n болохыг харж болно. Тиймээс f(4n + 1) = 1.

Одоо f(1)-ээс f(4n + 1) хүртэлх гишүүдээс 1-тэй тэнцүү утгуудыг судалбал f(17) = f(21) = \dots = f(4n + 1) = 1 болохыг олно. f-ийн тодорхойлолттой хослуулбал f(4n + 2) \geqslant n - 3 гэж гарна. Нөгөө талаас 4n + 1-ээр төгссөн a_1 < a_2 < \dots < a_m (= 4n + 1) арифметик прогрессийн хувьд хэрэв f(a_1) = \dots = f(a_m) = 1 бол уг арифметик прогрессийн ялгавар d \geqslant 4 байх ёстой (учир нь хэрэв d \leqslant 3 бол f(4n - 2), f(4n - 1), f(4n), f(4n + 1) тоонуудын ядаж хоёр нь 1-тэй тэнцүү байх шаардлагатай болох ба индукцийн таамаглал ёсоор зөвхөн f(4n + 1) = 1 байна). Хэрэв d > 4 бол индукцийн таамаглал болон f(1)-ээс f(36) хүртэлх утгуудаас d \geqslant 8 гэдгийг мэднэ. Иймд m \leqslant 1 + \frac{(4n + 1) - 1}{8} < n - 3 болно.
Тиймээс f(4n + 2) = n - 3.

Дараа нь f(1)-ээс f(4n + 2) хүртэлх утгуудыг авч үзвэл зөвхөн f(4n - 12) = f(4n + 2) = n - 3 биелнэ (энд бид n \geqslant 9 гэдгийг ашиглалаа), тиймээс f(4n + 3) = 2.
Эцэст нь f(4n + 2)-ийн утгыг шинжилсэнтэй яг ижил аргаар f(4n + 4) = n + 1 болохыг мэдэж болно.
Иймд аливаа n \in \mathbf{N}^* (n \geqslant 8) хувьд (1) ямагт биелнэ. Цаашилбал, аливаа n \in \mathbf{N}^* хувьд f(4n + 8) = n + 2 биелнэ.

Тайлбар. Зүй тогтлоос үр дүнг таамаглахын тулд тооцоолох шаардлагатай эхний утгуудын тоо нь бодлого бүрд харилцан адилгүй байж болно. Энэ тохиолдолд нягт нямбай байдал болон өөртөө итгэх итгэл хоёулаа чухал юм.

NoteЖишээ 5

Аливаа n \in \mathbf{N}^* хувьд 2^k \mid n ба 2^{k+1} \nmid n нөхцөлийг хангах сөрөг биш бүхэл k тоог \rho(n) гэж тэмдэглэе. \{x_n\} дараалал дараах байдлаар тодорхойлогдов: x_0 = 0, \quad \frac{1}{x_n} = 1 + 2\rho(n) - x_{n-1}, \quad n = 1, 2, \dots x_0, x_1, \dots дараалалд сөрөг биш рационал тоо бүр яг нэг удаа тааралдахыг батал.

Баталгаа. Хэрэв x_n = \frac{p_n}{q_n} (p_n, q_n \in \mathbf{N}^*, (p_n, q_n) = 1) гэж бичвэл бодлогын нөхцөл \frac{q_n}{p_n} = (1 + 2\rho(n)) - \frac{p_{n-1}}{q_{n-1}} хэлбэртэй болно.
p_n = q_{n-1} үед хуваарийг арилгахад хамгийн тохиромжтой. Энэ таамаглал дараах баталгаанд хөтөлнө.
\{y_n\} дарааллыг дараах байдлаар тодорхойлъё: y_1 = y_2 = 1, \quad y_{n+2} = (1 + 2\rho(n))y_{n+1} - y_n, \quad n = 1, 2, \dots Бид дараах дүгнэлтүүдэд ээлж дараалан хүрнэ.

Дүгнэлт 1. Аливаа n \in \mathbf{N}^* хувьд ямагт x_n = \frac{y_n}{y_{n+1}} биелнэ.
Үүнийг n-ээр индукцлэн баталъя. Индукцийн алхам дараах байдлаар хийгдэнэ: \begin{aligned} \frac{1}{x_{n+1}} &= 1 + 2\rho(n + 1) - x_n = 1 + 2\rho(n + 1) - \frac{y_n}{y_{n+1}} \\ &= \frac{1}{y_{n+1}}\big((1 + 2\rho(n + 1))y_{n+1} - y_n\big) \\ &= \frac{y_{n+2}}{y_{n+1}}. \end{aligned} Иймд x_{n+1} = \frac{y_{n+1}}{y_{n+2}}.

Дүгнэлт 2. Аливаа n \in \mathbf{N}^* хувьд ямагт y_{2n+1} = y_{n+1} + y_n, y_{2n} = y_n биелнэ.
n-ээр индукцлэе. Үнэн хэрэгтээ n үед Дүгнэлт 2 үнэн бол: \begin{aligned} y_{2n+2} &= (1 + 2\rho(2n + 1))y_{2n+1} - y_{2n} = y_{2n+1} - y_n = y_{n+1}; \\ y_{2n+3} &= (1 + 2\rho(2n + 2))y_{2n+2} - y_{2n+1} \\ &= (1 + 2(1 + \rho(n + 1)))y_{2n+2} - y_{2n+1} \\ &= 2y_{n+1} + (1 + \rho(n + 1))y_{n+1} - (y_{n+1} + y_n) \\ &= y_{n+1} + (1 + \rho(n + 1))y_{n+1} - y_n \\ &= y_{n+1} + y_{n+2}. \end{aligned} Эндээс болон анхны нөхцөлөөс Дүгнэлт 2 зөв болохыг мэднэ.

Дүгнэлт 2-ыг математикийн индукцтэй хослуулбал аливаа n \in \mathbf{N}^* хувьд ямагт (y_n, y_{n+1}) = 1 болохыг хялбархан баталж болно.

Дүгнэлт 3. (p, q) = 1 байх дурын p, q \in \mathbf{N}^* тоонуудын хувьд (p, q) = (y_n, y_{n+1}) биелэх цор ганц n \in \mathbf{N}^* оршино.
p + q нийлбэрээр индукцлэн баталъя. p + q = 2 үед p = q = 1 байна. Энэ үед (p, q) = (y_1, y_2) болох ба Дүгнэлт 2-оос n \geqslant 2 үед y_n ба y_{n+1}-ийн ядаж нэг нь 1-ээс их гэдгийг мэднэ. Иймд (y_n, y_{n+1}) \neq (y_1, y_2). Тиймээс p + q = 2 үед Дүгнэлт 3 үнэн.

Одоо p + q < m (m \geqslant 3, m \in \mathbf{N}^*) ба (p, q) = 1 нөхцөлийг хангах бүх эерэг бүхэл (p, q) хосуудын хувьд Дүгнэлт 3 үнэн гэж таамаглаад p + q = m тохиолдлыг авч үзье. Энэ үед p \neq q тул p < q ба p > q гэсэн хоёр тохиолдлоор хэлэлцье: - Тохиолдол 1: p < q. (p, q) = 1 гэдгээс (p, q - p) = 1 болох ба (q - p) + p = q < m байна. Индукцийн таамаглал ёсоор (p, q - p) = (y_n, y_{n+1}) байх цор ганц n \in \mathbf{N}^* оршино. Тэгвэл (p, q) = (y_n, y_n + y_{n+1}) = (y_{2n}, y_{2n+1}) болно (энд бид Дүгнэлт 2-ыг ашиглалаа).
Нөгөө талаас хэрэв (p, q) = (y_k, y_{k+1}) = (y_l, y_{l+1}) байх k < l (k, l \in \mathbf{N}^*) оршдог бол y_k = y_l, y_{k+1} = y_{l+1} байна. Хэрэв k ба l хоёулаа тэгш тоонууд бол Дүгнэлт 2 ёсоор (p, q - p) нь хоёр ялгаатай илэрхийлэлтэй болж индукцийн таамаглалтай зөрчилдөнө. Харин k сондгой үед y_k > y_{k+1} болох нь p < q гэдэгтэй зөрчилдөнө. Иймд k тэгш тоо бөгөөд үүнтэй ижил үндэслэлээр l мөн тэгш тоо байна. Тиймээс (p, q) = (y_n, y_{n+1}) байх цорын ганц n \in \mathbf{N}^* оршино. - Тохиолдол 2: p > q. Тохиолдол 1-тэй ижил аргаар батална.

Дээрхийг нэгтгэвэл Дүгнэлт 3 биелнэ.
