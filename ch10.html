10. Кошийн тэнцэтгэл бишийн хэд хэдэн баталгаа

Энэ параграфаас эхлэн бид математикийн индукцийг хэрэглэх өөр зарим хэлбэр, арга техникийг авч үзэх болно.

TipКошийн (AM-GM) тэнцэтгэл биш

a_1, a_2, \dots, a_n нь n ширхэг эерэг бодит тоо байг. Тэгвэл: \frac{a_1 + a_2 + \dots + a_n}{n} \geqslant \sqrt[n]{a_1 a_2 \cdots a_n}. \tag{1} \frac{1}{n}(a_1 + \dots + a_n)-ийг a_1, a_2, \dots, a_n тоонуудын арифметик дундаж, харин \sqrt[n]{a_1 a_2 \cdots a_n}-ийг a_1, a_2, \dots, a_n тоонуудын геометр дундаж гэж нэрлэнэ.

Баталгаа 1. n = 1 үед (1) биелэх нь илэрхий; n = 2 үед (1) нь a_1 + a_2 \geqslant 2\sqrt{a_1 a_2} буюу (\sqrt{a_1} - \sqrt{a_2})^2 \geqslant 0 тэнцэтгэл биштэй эквивалент. Иймд (1) биелнэ.
Одоо n (n \geqslant 2) үед (1) биелнэ гэж таамаглаад n + 1 тохиолдлыг авч үзье.
A = \frac{1}{n + 1}(a_1 + \dots + a_{n+1}) гэе. Тэгвэл индукцийн таамаглал ёсоор: \begin{aligned} \frac{1}{2n}\Big(a_1 + \dots + a_{n+1} + \underbrace{A + \dots + A}_{n - 1 \text{ ширхэг}}\Big) &= \frac{1}{2n}(a_1 + \dots + a_n) + \frac{1}{2n}\Big(a_{n+1} + \underbrace{A + \dots + A}_{n - 1 \text{ ширхэг}}\Big) \\ &\geqslant \frac{1}{2}\Big(\sqrt[n]{a_1 \cdots a_n} + \sqrt[n]{a_{n+1} \underbrace{A \cdots A}_{n - 1 \text{ ширхэг}}}\Big) \\ &\geqslant \sqrt{\sqrt[n]{a_1 \cdots a_n} \cdot \sqrt[n]{a_{n+1} \cdot A^{n-1}}} \\ &= \sqrt[2n]{a_1 \cdots a_{n+1} A^{n-1}}. \end{aligned} a_1 + \dots + a_{n+1} = (n + 1)A гэдгийг тооцвол: \frac{1}{2n}\Big(a_1 + \dots + a_{n+1} + \underbrace{A + \dots + A}_{n - 1 \text{ ширхэг}}\Big) = \frac{1}{2n}((n + 1)A + (n - 1)A) = A. Тиймээс A \geqslant \sqrt[2n]{a_1 \cdots a_{n+1} A^{n-1}}, цаашилбал A^{n+1} \geqslant a_1 \cdots a_{n+1} болох тул: \frac{1}{n + 1}(a_1 + \dots + a_{n+1}) \geqslant \sqrt[n+1]{a_1 \cdots a_{n+1}}. Иймд n + 1 үед (1) биелнэ.
Тиймээс аливаа n \in \mathbf{N}^* хувьд (1) тэнцэтгэл биш биелнэ.

Тайлбар. Энэ бол математикийн индукцийн нэгдүгээр хэлбэрээр гаргасан (1)-ийн туйлын уран баталгаа юм.

Баталгаа 2. (1) нь n = 2 үед биелдэг тул (баталгаа нь Баталгаа 1-тэй ижил) математикийн индукцээр (1) нь бүх n = 2^k (k \in \mathbf{N}^*) хувьд биелэхийг хялбархан баталж болно.
Үнэхээр, хэрэв 2^k үед (1) биелдэг бол n = 2^{k+1} үед: \begin{aligned} \frac{1}{2^{k+1}}(a_1 + \dots + a_{2^{k+1}}) &= \frac{1}{2}\left(\frac{1}{2^k}(a_1 + \dots + a_{2^k}) + \frac{1}{2^k}(a_{2^k + 1} + \dots + a_{2^{k+1}})\right) \\ &\geqslant \frac{1}{2}\left(\sqrt[2^k]{a_1 \cdots a_{2^k}} + \sqrt[2^k]{a_{2^k + 1} \cdots a_{2^{k+1}}}\right) \\ &\geqslant \sqrt{\sqrt[2^k]{a_1 \cdots a_{2^k}} \cdot \sqrt[2^k]{a_{2^k + 1} \cdots a_{2^{k+1}}}} \\ &= \sqrt[2^{k+1}]{a_1 a_2 \cdots a_{2^{k+1}}}. \end{aligned} Өөрөөр хэлбэл, (1) нь бүх n = 2^k (k = 1, 2, \dots) хувьд биелнэ.
Одоо дурын n тохиолдлыг авч үзье. Аливаа n \in \mathbf{N}^* хувьд 2^k \leqslant n < 2^{k+1} байх k \in \mathbf{N} тоог сонгож аваад A = \frac{1}{n}(a_1 + \dots + a_n) гэе. Өмнөх үр дүнгээс: \frac{1}{2^{k+1}}\Big(a_1 + \dots + a_n + \underbrace{A + \dots + A}_{2^{k+1} - n \text{ ширхэг}}\Big) \geqslant \sqrt[2^{k+1}]{a_1 \cdots a_n \underbrace{A \cdots A}_{2^{k+1} - n \text{ ширхэг}}}. a_1 + \dots + a_n = nA гэдгийг тооцвол: A \geqslant \sqrt[2^{k+1}]{a_1 \cdots a_n A^{2^{k+1} - n}}. Цаашилбал A^n \geqslant a_1 \cdots a_n болно. Иймд n-ийн хувьд (1) биелнэ.

Тайлбар. Энэ баталгаа тун жам ёсны бөгөөд өмнөх хоёр баталгаа хоёулаа гишүүдийг нөхөж эвлүүлэх аргыг ашигласан болно.

Баталгаа 3. Өмнөх баталгаанаас (1) нь n = 2^k үед биелдэг буюу (1) биелэх төгсгөлгүй олон эерэг бүхэл n тоо оршино гэдгийг харлаа.
Одоо n + 1 үед (1) биелнэ гэж таамаглая. n тохиолдлын хувьд A = \frac{1}{n}(a_1 + \dots + a_n) гэж тэмдэглэвэл: \frac{1}{n + 1}(a_1 + \dots + a_n + A) \geqslant \sqrt[n+1]{a_1 \cdots a_n \cdot A}. a_1 + \dots + a_n = nA гэдгийг тооцвол A \geqslant \sqrt[n+1]{a_1 \cdots a_n \cdot A}, улмаар A \geqslant \sqrt[n]{a_1 \cdots a_n} болох бөгөөд энэ нь n-ийн хувьд (1) биелэхийг харуулна.
Иймд аливаа n \in \mathbf{N}^* хувьд (1) биелнэ.

Тайлбар. Бид энд «нүх бөглөх» санааг хэрэглэсэн бөгөөд энэ нь урвуу математикийн индукцийн үндсэн хэрэглээ юм.

ImportantУрвуу (буцах) математикийн индукц

Эерэг бүхэл n тооны тухай P(n) өгүүлбэр (эсвэл шинж чанар) дараах хоёр нөхцөлийг хангадаг байг:

  1. P(n) нь төгсгөлгүй олон эерэг бүхэл n тооны хувьд үнэн;
  2. P(n + 1) үнэн гэдгээс P(n) үнэн гэдэг нь мөрдөн гардаг.

Тэгвэл аливаа n \in \mathbf{N}^* хувьд P(n) үнэн байна.

Баталгаа. Эсрэгээс нь баталъя.
Хэрэв P(m) худал байх m \in \mathbf{N}^* оршдог бол математикийн индукцээр аливаа n \geqslant m хувьд P(n) худал болохыг баталж чадна (тэгвэл P(n) үнэн байх зөвхөн төгсгөлөг тооны n \in \mathbf{N}^* орших болж (1) нөхцөлтэй зөрчилдөнө).
Үнэхээр, таамаглал ёсоор P(m) худал. Одоо P(n) (n \geqslant m) худал гэж таамаглавал (2)-оос P(n + 1) мөн худал гэдэг нь мөрдөн гарна ((2)-ын эсрэг дүгнэлт ёсоор).
Тиймээс математикийн индукцээр аливаа n \geqslant m хувьд P(n) худал болж зөрчил үүснэ. Иймд урвуу индукц үнэн.

Кошийн тэнцэтгэл бишийн сүүлийн хоёр баталгаа хоёулаа эхлээд өгүүлбэр төгсгөлгүй олон n \in \mathbf{N}^* хувьд үнэн болохыг батлаад, дараа нь бүх n \in \mathbf{N}^* хувьд үнэн болохыг харуулсан. Энэ санааг олон бодлогод хэрэглэдэг.
Кошийн тэнцэтгэл биш нь математикт хамгийн олон баталгаатай теорем байж магадгүй. Бид энд зөвхөн математикийн индукц ашигласан хамгийн түгээмэл аргуудыг орууллаа. Эдгээр санаа, аргыг бусад бодлогод мөн хэрэглэж болно.

NoteЖишээ 1

f: \mathbf{N}^* \to [1, +\infty) функц дараах нөхцөлүүдийг хангадаг байг:

  1. f(2) = 2;
  2. Аливаа m, n \in \mathbf{N}^* хувьд f(mn) = f(m)f(n);
  3. m < n үед f(m) < f(n).

Аливаа эерэг бүхэл n тооны хувьд f(n) = n биелэхийг батал.

Баталгаа. (1) ба (2) нөхцөлөөс f(1) = 1 гэдэг нь мөрдөн гарна.
Одоо f(2^k) = 2^k (k \in \mathbf{N}) гэж таамаглая. Тэгвэл f(2^{k+1}) = f(2^k)f(2) = 2^k \times 2 = 2^{k+1}. Иймд аливаа k \in \mathbf{N} хувьд f(2^k) = 2^k.

Одоо f(n)-ийн утгыг авч үзье. f(n) = l гэе. Тэгвэл (2) болон математикийн индукц ёсоор аливаа m \in \mathbf{N}^* хувьд f(n^m) = l^m байна.
2^k \leqslant n^m < 2^{k+1} байхаар k-г сонговол (3) ёсоор f(2^k) \leqslant f(n^m) < f(2^{k+1}) болно. Тиймээс өмнөх үр дүнгээс 2^k \leqslant l^m < 2^{k+1} гэж гарна. 2^k \leqslant n^m < 2^{k+1} гэдгийг тооцвол: \frac{1}{2} < \left(\frac{n}{l}\right)^m < 2. \tag{1} Энэ тэнцэтгэл биш аливаа m \in \mathbf{N}^* хувьд биелнэ.
Хэрэв n > l бол m > \frac{l}{n - l} байхаар m-ийг сонгоё. Тэгвэл: \left(\frac{n}{l}\right)^m = \left(1 + \frac{n - l}{l}\right)^m \geqslant 1 + m \cdot \frac{n - l}{l} > 2, энэ нь (1)-тэй зөрчилдөнө. Үүнтэй адилаар хэрэв n < l бол m > \frac{n}{l - n} байхаар m-ийг сонговол \left(\frac{l}{n}\right)^m > 2, өөрөөр хэлбэл \left(\frac{n}{l}\right)^m < \frac{1}{2} болж мөн (1)-тэй зөрчилдөнө.
Тиймээс зөвхөн n = l байх боломжтой.
Дээрхийг нэгтгэвэл аливаа n \in \mathbf{N}^* хувьд f(n) = n.

Тайлбар. Хэрэв f функц \mathbf{N}^*-ээс \mathbf{N}^* руу буулгах буулгалт байсан бол бодлого илүү хялбар болох бөгөөд үүнийг уншигчдад үлдээе.
Үүнтэй ижил аргаар алдарт Иенсений (Jensen) тэнцэтгэл бишийг мөн баталж болно.

NoteЖишээ 2

Аливаа m, n \in \mathbf{N}^* хувьд f(m)^2 + f(n) \mid (m^2 + n)^2 \tag{1} нөхцөлийг хангах f: \mathbf{N}^* \to \mathbf{N}^* бүх функцийг ол.

Бодолт. f нь нөхцөлийг хангах функц байг. (1)-д m = n = 1 гэж орлуулбал (f(1)^2 + f(1)) \mid 4, өөрөөр хэлбэл f(1)(f(1) + 1) \mid 4 болно. Хэрэв f(1) \geqslant 2 бол f(1)(f(1) + 1) \geqslant 6 болох тул зөвхөн f(1) = 1 байх боломжтой.

Аливаа анхны p тооны хувьд эхлээд f(p - 1) = p - 1 \tag{2} болохыг баталъя.
Үнэхээр, дурын анхны p тооны хувьд (1)-д m = 1, n = p - 1 гэж орлуулбал (f(1) + f(p - 1)) \mid p^2, өөрөөр хэлбэл (1 + f(p - 1)) \mid p^2 болно. Иймд f(p - 1) + 1 = p эсвэл p^2 байна. Хэрэв эхнийх нь үнэн бол (2) биелнэ; хэрэв сүүлийнх нь буюу f(p - 1) = p^2 - 1 бол (1)-д m = p - 1, n = 1 гэж орлуулъя. Тэгвэл (f(p - 1)^2 + f(1)) \mid ((p - 1)^2 + 1)^2, өөрөөр хэлбэл ((p^2 - 1)^2 + 1) \mid ((p - 1)^2 + 1)^2 болно. Гэвч \begin{aligned} ((p - 1)^2 + 1)^2 &\leqslant ((p - 1)^2 + (p - 1))^2 \\ &= p^2(p - 1)^2 < (p + 1)^2(p - 1)^2 + 1 \\ &= (p^2 - 1)^2 + 1 \end{aligned} болох тул зөрчил үүснэ. Тиймээс (2) биелнэ.

Одоо аливаа n \in \mathbf{N}^* хувьд f(n) = n болохыг баталъя.
Үнэхээр, дурын эерэг бүхэл n тооны хувьд k + 1 нь анхны тоо байх k \in \mathbf{N}^* тоог сонгож авч болно (ийм k төгсгөлгүй олон оршино). (1)-д m = k гэж орлуулаад (2)-той хослуулбал: (k^2 + f(n)) \mid (k^2 + n)^2. \tag{3} (k^2 + n)^2 = (k^2 + f(n) + n - f(n))^2 = A(k^2 + f(n)) + (n - f(n))^2 (энд A нь бүхэл тоо) гэдгийг тооцвол (3)-аас (k^2 + f(n)) \mid (n - f(n))^2 болно. Энэ томьёо нь (n - f(n))^2 тоо төгсгөлгүй олон эерэг бүхэл тоонд хуваагддаг болохыг харуулж байна (учир нь k-г сонгох төгсгөлгүй олон арга бий). Иймд (n - f(n))^2 = 0 буюу f(n) = n.

Дүгнэж хэлбэл, нөхцөлийг хангах цорын ганц f(n) = n функц оршино.

Тайлбар. Үндсэндээ төгсгөлгүй олон k \in \mathbf{N}^* хувьд f(k) = k биелэхийг батлаад, дараа нь үлдсэн «нүхнүүдийг» бөглөхөд хангалттай. Хуваагчийн тоог аль болох цөөн байлгахын тулд бид (2)-оос эхлэн бодлогыг задаллаа. Энэ аргыг хуваагдах чанарын онолд түгээмэл хэрэглэдэг.

NoteЖишээ 3

Аливаа n \in \mathbf{N}^* болон анхны p тооны хувьд f(n)^p \equiv n \pmod{f(p)} \tag{1} нөхцөлийг хангах f: \mathbf{N}^* \to \mathbf{N}^* бүх функцийг ол.

Бодолт. Аливаа анхны p тооны хувьд (1)-д n = p гэж авбал p \equiv f(p)^p \equiv 0 \pmod{f(p)} болно. Иймд f(p) \mid p болох тул f(p) = 1 эсвэл p байна.
Одоо S = \{p \mid p \text{ нь анхны тоо}, \; f(p) = p\} гэж тэмдэглэе. Бодлогыг гурван тохиолдолд хувааж авч үзье:

  • Тохиолдол 1: S нь төгсгөлгүй олонлог. Өмнөх жишээний аргаар аливаа n \in \mathbf{N}^* хувьд f(n) = n болохыг баталж чадна.
    Үнэхээр, f(p) = p байх төгсгөлгүй олон анхны p тоо оршино. Тиймээс дурын n \in \mathbf{N}^* хувьд n \equiv f(n)^p \pmod{p} байх төгсгөлгүй олон анхны p тоо оршино. Фермагийн бага теорем ёсоор f(n)^p \equiv f(n) \pmod{p} тул f(n) \equiv n \pmod{p} болж, f(n) - n нь төгсгөлгүй олон анхны тооны хуваагдагч болно. Иймд f(n) = n.

  • Тохиолдол 2: S нь хоосон олонлог. Тэгвэл дурын анхны p тооны хувьд f(p) = 1 байна. Энэ үед үлдсэн эерэг бүхэл n тоонуудын хувьд f(n) нь дурын эерэг бүхэл утгыг авч болно (иймд (1) ямагт биелнэ).

  • Тохиолдол 3: S нь хоосон биш төгсгөлөг олонлог.
    S олонлогийн хамгийн их анхны тоог p гэе. Хэрэв p \geqslant 3 бол зөрчилд хүрнэ гэдгийг баталъя. Иймд S = \{2\} болно.
    p нь хамгийн их тул дурын q > p анхны тооны хувьд f(q) = 1 байна. (1)-ээс q \equiv f(q)^p \equiv 1 \pmod{p} буюу q \equiv 1 \pmod{p} гэж гарна.
    Одоо p-ээс ихгүй бүх сондгой анхны тоонуудын үржвэрийг Q гэе. Тэгвэл Q + 2-ын анхны хуваагч бүр p-ээс их байна (энд бид p \geqslant 3 гэдгийг ашиглалаа). Дээрх үр дүнтэй хослуулбал Q + 2 \equiv 1 \pmod{p} болох ба эндээс p \mid Q + 1 болж, p \mid Q гэдэгтэй зөрчилдөнө.

Дээрх шинжилгээнээс S = \{2\} болохыг харлаа. Иймд f(2) = 2, харин сондгой анхны p тооны хувьд f(p) = 1 байна. (1) ёсоор бид зөвхөн f(n)^2 \equiv n \pmod{2} биелэхийг хангахад хангалттай. Тиймээс бусад эерэг бүхэл n тооны хувьд f(n) нь n-тэй ижил тэгш сондгой чанартай дурын эерэг бүхэл утгыг авахад хүрэлцээтэй.

Шууд шалгаж үзвэл дээрх гурван тохиолдол дахь функц бүр бодлогын нөхцөлийг хангана. Эдгээр нь бидний хайж буй бүх функц юм.

Тайлбар. \mathbf{N}^* \to \mathbf{N}^* функцүүдийг олох нь үндсэндээ эерэг бүхэл тоон \{f(n)\} дарааллыг судлахтай адил юм. Бид энд тооны онолын аргаас уламжлан анхны үржигдэхүүний шинжилгээг хэрэглэлээ. Үүнтэй адилаар функцэн тэгшитгэлийн зарим санааг мөн эдгээр бодлогод ашиглаж болно.

NoteЖишээ 4

Өгөгдсөн эерэг бүхэл k тооны хувьд аливаа m, n \in \mathbf{N}^* үед (f(m) + f(n)) \mid (m + n)^k \tag{1} нөхцөлийг хангах f: \mathbf{N}^* \to \mathbf{N}^* бүх функцийг ол.

Бодолт. f(n) = n функц нөхцөлийг хангах нь илэрхий. Энэ нь цорын ганц шийд мөн үү? Үүнийг баталъя.

Эхлээд f нь инъектив (харилцан нэг утгатай) буулгалт болохыг баталъя.
Үнэхээр, хэрэв a \neq b бөгөөд f(a) = f(b) байх a, b \in \mathbf{N}^* оршдог бол (1)-ээс аливаа n \in \mathbf{N}^* хувьд (f(a) + f(n)) \mid (a + n)^k, \quad (f(b) + f(n)) \mid (b + n)^k гэж гарна. Иймд дурын n \in \mathbf{N}^* хувьд f(a) + f(n) нь (a + n)^k ба (b + n)^k-ийн ерөнхий хуваагч болно.
Одоо p > \max\{a, |b - a|\} байх анхны p тоог авч, n = p - a гэе. (a + n, b + n) = (a + n, b - a) = (p, b - a) = 1 тул ((a + n)^k, (b + n)^k) = 1 болно. Үр дүнд нь f(a) + f(n) = 1 болж, f(a), f(n) хоёулаа эерэг бүхэл тоонууд гэдэгтэй зөрчилдөнө. Тиймээс f нь инъектив буулгалт мөн.

Дараа нь аливаа m \in \mathbf{N}^* хувьд |f(m + 1) - f(m)| = 1 болохыг баталъя.
(1)-д (m, n) ба (m + 1, n) хосуудыг хэрэглэвэл: \begin{aligned} (f(m) + f(n)) &\mid (m + n)^k, \\ (f(m + 1) + f(n)) &\mid (m + 1 + n)^k. \end{aligned} (m + n, m + 1 + n) = 1 тул (f(m) + f(n), f(m + 1) + f(n)) = 1 болно.
Цаашилбал, m-ийг бэхэлсэн үед аливаа n \in \mathbf{N}^* хувьд: (f(n) + f(m), f(m + 1) - f(m)) = 1. \tag{2} Хэрэв |f(m + 1) - f(m)| \neq 1 бол p \mid |f(m + 1) - f(m)| байх анхны p тоо оршино. Одоо n = p^\alpha - m нь эерэг бүхэл тоо байхаар \alpha \in \mathbf{N}^* тоог сонгоё. Тэгвэл (1)-ээс (f(n) + f(m)) \mid p^{\alpha k} болох тул f(n) + f(m) = p^l (l \in \mathbf{N}^*) болно. Үр дүнд нь (f(n) + f(m), f(m + 1) - f(m)) = (p^l, f(m + 1) - f(m)) \geqslant p болж (2)-той зөрчилдөнө.

Эцэст нь аливаа n \in \mathbf{N}^* хувьд f(n) = n болохыг баталъя.
Өмнөх үр дүнгээс дурын m \in \mathbf{N}^* хувьд f(m + 1) - f(m) = 1 эсвэл f(m + 1) - f(m) = -1 биелнэ. Хэрэв нэг f функцийн хувьд энэ хоёр тохиолдол хоёулаа зэрэг гардаг бол (f(m + 1) - f(m), f(m + 2) - f(m + 1)) = (1, -1) эсвэл (-1, 1) байх m \in \mathbf{N}^* оршино. Аль ч тохиолдолд f(m + 2) = f(m) болж f инъектив гэдэгтэй зөрчилдөнө. Тиймээс бүх m \in \mathbf{N}^* хувьд f(m + 1) - f(m) = 1 эсвэл бүх m \in \mathbf{N}^* хувьд f(m + 1) - f(m) = -1 биелэх ёстой.

f нь \mathbf{N}^* \to \mathbf{N}^* функц тул зөвхөн аливаа m \in \mathbf{N}^* хувьд f(m + 1) - f(m) = 1 байх боломжтой. Иймд дурын n \in \mathbf{N}^* хувьд f(n) = n + c (энд c = f(1) - 1 \geqslant 0).
Хэрэв c > 0 бол p > 2c байх анхны p тоог авъя. (1) ёсоор f(1) + f(p - 1) \mid p^k буюу p + 2c \mid p^k болох тул p + 2c нь p-ийн зэрэг байх ёстой. Иймд p \mid p + 2c, улмаар p \mid 2c болж зөрчил үүснэ. Тиймээс c = 0.

Дүгнэж хэлбэл, зөвхөн f(n) = n функц нөхцөлийг хангана.
