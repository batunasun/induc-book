5. Арифметик прогресс ба геометр прогресс

Арифметик прогресс ба геометр прогресс нь хамгийн энгийн хоёр төрлийн дараалал юм. Бид бусад дарааллуудыг ихэвчлэн эдгээр рүү хувиргаж боддог.

Хэрэв дараалсан гишүүдийн ялгавар (харгалзан харьцаа) тогтмол байвал уг дарааллыг арифметик (харгалзан геометр) прогресс гэнэ. Энэ тогтмол тоог дарааллын ялгавар (харгалзан хуваарь) гэх бөгөөд ихэвчлэн d (харгалзан q)-ээр тэмдэглэдэг. Тэг тоо хуваарилагч байж чадахгүй тул q \neq 0 гэдгийг анхаарна уу.

Арифметик болон геометр прогрессийн ерөнхий гишүүн, нийлбэр олоход дараах томьёонуудыг ашиглана:

  1. \{a_n\} арифметик прогрессийн эхний n гишүүний нийлбэрийг S_n гэе. Тэгвэл: a_n = a_1 + (n - 1)d, S_n = \frac{1}{2}(a_1 + a_n)n = a_1 n + \frac{n(n - 1)}{2}d.
  2. \{a_n\} геометр прогрессийн эхний n гишүүний нийлбэрийг S_n гэе. Тэгвэл a_n = a_1 \cdot q^{n-1} бөгөөд: S_n = \begin{cases} n a_1, & \text{хэрэв } q = 1, \\ \dfrac{a_1(1 - q^n)}{1 - q}, & \text{хэрэв } q \neq 1. \end{cases}
  3. Хэрэв \{a_n\} геометр прогресс нь төгсгөлгүй дараалал бөгөөд хуваарь q нь |q| < 1 нөхцөлийг хангадаг бол түүнийг төгсгөлгүй буурах геометр прогресс гэнэ. Түүний бүх гишүүний нийлбэр нь S = \frac{a_1}{1 - q} байна.
NoteЖишээ 1

n^2 (n \geqslant 4) ширхэг эерэг бодит тоог n мөр, n баганатай хүснэгтэд байрлуулав: \begin{array}{cccc} a_{11} & a_{12} & \dots & a_{1n} \\ a_{21} & a_{22} & \dots & a_{2n} \\ \dots & \dots & \dots & \dots \\ a_{n1} & a_{n2} & \dots & a_{nn} \end{array} Мөр бүрийн тоонууд арифметик прогресс, харин багана бүрийн тоонууд ижил хуваарьтай геометр прогресс үүсгэнэ. Хэрэв a_{24} = 1, a_{42} = \frac{1}{8}, a_{43} = \frac{3}{16} бол a_{11} + a_{22} + \dots + a_{nn} нийлбэрийн утгыг ол.

Бодолт. Багана бүрийн тоонуудаас бүрдэх геометр прогрессийн хуваарийг q гэе. Тэгвэл a_{44} = a_{24} \cdot q^2 = q^2 болно.
Дөрөвдүгээр мөрний тоонууд арифметик прогресс үүсгэх тул a_{42}, a_{43}, a_{44} нь мөн арифметик прогресс болно. Иймд a_{42} + a_{44} = 2a_{43} буюу: \frac{1}{8} + q^2 = \frac{6}{16}. Тиймээс q^2 = \frac{1}{4}. Хүснэгтийн бүх тоо эерэг бодит тоо гэдгийг тооцвол q = \frac{1}{2} гарна.

Дөрөвдүгээр мөрний тоонууд арифметик прогресс үүсгэх ба a_{42} = \frac{1}{8}, a_{43} = \frac{3}{16} тул уг арифметик прогрессийн ялгавар нь \frac{3}{16} - \frac{1}{8} = \frac{1}{16} байна. Иймд эхний гишүүн a_{41} = \frac{1}{8} - \frac{1}{16} = \frac{1}{16} болно. Тэгвэл аливаа 1 \leqslant k \leqslant n хувьд a_{4k} = \frac{k}{16}.
k-р багана нь \frac{1}{2} хуваарьтай геометр прогресс тул: a_{1k} = a_{4k} \cdot q^{-3} = \frac{k}{16} \cdot \left(\frac{1}{2}\right)^{-3} = \frac{k}{2}. Тиймээс аливаа 1 \leqslant m \leqslant n хувьд a_{mk} = a_{1k} \cdot q^{m-1} = \frac{k}{2^m}. Цаашилбал a_{mm} = \frac{m}{2^m}.

S = a_{11} + a_{22} + \dots + a_{nn} гэе. Тэгвэл S = \sum_{m=1}^n \frac{m}{2^m} ба \frac{S}{2} = \sum_{m=1}^n \frac{m}{2^{m+1}} болно. Энэ хоёр тэнцэтгэлийг харгалзуулан хасвал: \begin{aligned} \frac{1}{2}S &= \sum_{m=1}^n \frac{m}{2^m} - \sum_{m=1}^n \frac{m}{2^{m+1}} \\ &= \sum_{m=1}^n \frac{m}{2^m} - \sum_{m=2}^{n+1} \frac{m - 1}{2^m} \\ &= \frac{1}{2} + \sum_{m=2}^n \left(\frac{m}{2^m} - \frac{m - 1}{2^m}\right) - \frac{n}{2^{n+1}} \\ &= \frac{1}{2} + \sum_{m=2}^n \frac{1}{2^m} - \frac{n}{2^{n+1}} \\ &= \sum_{m=1}^n \frac{1}{2^m} - \frac{n}{2^{n+1}} = 1 - \frac{1}{2^n} - \frac{n}{2^{n+1}} \\ &= 1 - \frac{n + 2}{2^{n+1}}. \end{aligned} Иймд S = 2 - \frac{n + 2}{2^n}.

NoteЖишээ 2

x-ийн хувьд авч үзсэн (2a - 1)\sin x + (2 - a)\sin 2x = \sin 3x тэгшитгэлийн сөрөг биш бодит шийдүүдийг өсөх эрэмбээр байрлуулахад төгсгөлгүй арифметик прогресс үүсгэдэг бол a-гийн утгын мужийг ол.

Бодолт. Тэгшитгэлийг дараах хэлбэрт хувиргая: \begin{aligned} &2a\sin x - a\sin 2x + 2\sin 2x - \sin x - \sin 3x = 0 \\ \iff &2a\sin x(1 - \cos x) + 2\sin 2x - 2\sin 2x \cos x = 0 \\ \iff &(2a\sin x - 2\sin 2x)(1 - \cos x) = 0. \end{aligned} Тэгвэл 1 - \cos x = 0 эсвэл \sin 2x = a\sin x биелнэ.
Эхний тэгшитгэлийн сөрөг биш бодит шийдүүд нь x = 2k_1 \pi (k_1 \in \mathbf{N}). Хоёр дахь тэгшитгэлийг \sin x = 0 эсвэл \cos x = \frac{a}{2} хэлбэрт шилжүүлж болно. \sin x = 0 тэгшитгэлийн сөрөг биш бодит шийдүүд нь x = k_2 \pi (k_2 \in \mathbf{N}).
\cos x = \frac{a}{2} тэгшитгэл зөвхөн |a| \leqslant 2 үед л шийдтэй бөгөөд сөрөг биш бодит шийдүүд нь x = 2k_3 \pi + \arccos \frac{a}{2} эсвэл x = 2k_4 \pi + \pi + \arccos \frac{a}{2} (k_3, k_4 \in \mathbf{N}) болно.

Дүгнэж хэлбэл, |a| \geqslant 2 үед тэгшитгэлийн сөрөг биш бодит шийдүүд нь x = k\pi (k \in \mathbf{N}) болох ба эдгээр нь арифметик прогресс үүсгэнэ.
|a| < 2 үед тэгшитгэлийн сөрөг биш бодит шийдүүд нь x = k\pi (k \in \mathbf{N}), эсвэл x = 2k_3 \pi + \arccos \frac{a}{2}, эсвэл x = 2k_4 \pi + \pi + \arccos \frac{a}{2} болно. Тэгвэл зөвхөн \arccos \frac{a}{2} = \frac{\pi}{2} буюу a = 0 үед л тэгшитгэлийн бүх сөрөг биш бодит шийдүүд багаас их рүү өсөх төгсгөлгүй арифметик прогресс үүсгэнэ.
Иймд нөхцөлийг хангах a-гийн утгын муж нь: a \in (-\infty, -2] \cup \{0\} \cup [2, +\infty).

NoteЖишээ 3

Эерэг бүхэл тооны хоёр төгсгөлгүй дараалал өгөгдөв. Нэг нь d (d > 0) ялгавартай арифметик прогресс, нөгөө нь q (q > 1) хуваарьтай геометр прогресс бөгөөд d ба q нь харилцан анхны тоонууд юм. Хэрэв хоёр дараалалд нэг ерөнхий гишүүн байвал тэдгээрт төгсгөлгүй олон ерөнхий гишүүн оршино гэдгийг батал.

Баталгаа. Хоёр дарааллыг харгалзан \{a + nd\} (n = 0, 1, 2, \dots) ба \{b q^m\} (m = 0, 1, 2, \dots) гэе (энд a, b, d, q нь эерэг бүхэл тоонууд ба q > 1).
Хэрэв нэг ерөнхий гишүүн байвал ерөнхий чанарыг алдагдуулахгүйгээр хоёр дарааллын эхний гишүүд ижил гэж үзье. Эс тэгвээс хоёр дарааллын ерөнхий гишүүнээс өмнөх төгсгөлөг тооны гишүүдийг хасахад a = b болно. Тэгвэл төгсгөлгүй олон ерөнхий гишүүн оршино гэдгийг батлахын тулд a q^m \equiv a \pmod{d} нөхцөлийг хангах төгсгөлгүй олон m \in \mathbf{N}^* оршино гэдгийг батлахад хангалттай. Үүний тулд зөвхөн q^m \equiv 1 \pmod{d} байхад хангалттай.

1, q, q^2, \dots, q^d тоонуудыг d-д хуваахад гарах үлдэгдэл нь зөвхөн d ширхэг утга авах тул Дирихлейн зарчим ёсоор q^j \equiv q^i \pmod{d} байх 0 \leqslant i < j \leqslant d оршино. (d, q) = 1 тул q^{j-i} \equiv 1 \pmod{d} гэж гарна. Цаашилбал аливаа n \in \mathbf{N}^* хувьд m = (j - i)n гэж авбал q^m = (q^{j-i})^n \equiv 1^n = 1 \pmod{d} болно.
Иймд өгүүлбэр үнэн.

Тайлбар. Хэрэв уншигчид Эйлерийн теоремыг мэддэг бол (d, q) = 1 үед q^{\varphi(d)} \equiv 1 \pmod{d} чанарыг ашиглан нөхцөлийг хангах m тоог мөн олж чадна.

NoteЖишээ 4

\{a_n\} дараалал дараах байдлаар тодорхойлогдов: a_1 = 1\,000\,000, \quad a_{n+1} = n\left[\frac{a_n}{n}\right] + n, \quad n = 1, 2, \dots \{a_n\} дараалалд арифметик прогресс үүсгэх төгсгөлгүй дэд дараалал оршихыг батал (нөгөө дарааллын гишүүдээс түүж байгуулсан дарааллыг түүний дэд дараалал гэнэ).

Баталгаа. x_n = \frac{a_{n+1}}{n} гэе. Тэгвэл аливаа n \in \mathbf{N}^* хувьд x_n = \left[\frac{a_n}{n}\right] + 1 \in \mathbf{N}^* болох ба \{x_n\} нь эерэг бүхэл тоон дараалал болно.
Цаашилбал n \in \mathbf{N}^* хувьд: \begin{aligned} x_{n+1} &= \left[\frac{a_{n+1}}{n + 1}\right] + 1 = \left[\frac{n x_n}{n + 1}\right] + 1 \\ &= x_n + \left[-\frac{x_n}{n + 1}\right] + 1 \\ &\leqslant x_n + (-1) + 1 = x_n. \end{aligned} Энэ нь \{x_n\} дараалал үл өсөх болохыг харуулна. Тиймээс \{x_n\} дараалал тодорхой нэг гишүүнээсээ эхлэн тогтмол дараалал болно (учир нь бүх x_n нь эерэг бүхэл тоонууд). Энэ тогтмол тоог k гэе. Тэгвэл тэр гишүүнээс эхлэн a_n = kn болно. Иймд \{a_n\} нь тэр гишүүнээсээ эхлэн арифметик прогресс болно.
Өгүүлбэр батлагдлаа.

Тайлбар. Энэ бодлогын дүгнэлт нь анхны утгаас хамаарахгүй (бидэнд зөвхөн a_1 \geqslant 0 байхад л хангалттай). Энэ бодлогыг бодохдоо эерэг бүхэл тооны дурын төгсгөлгүй үл өсөх дараалал тодорхой нэг гишүүнээсээ эхлэн тогтмол болдог гэсэн илэрхий үр дүнг ашиглалаа.

NoteЖишээ 5

Өгөгдсөн дурын эерэг бүхэл n \geqslant 3 тооны хувьд b_1 < a_1 < b_2 < a_2 < \dots < b_n < a_n \tag{1} нөхцөлийг хангах арифметик прогресс a_1, a_2, \dots, a_n болон геометр прогресс b_1, b_2, \dots, b_n оршихыг батал.

Баталгаа. Зэрэгт өсөлт нь шугаман өсөлтөөс илүү хурдан гэдгийг ажиглая. Иймд аливаа m \in \mathbf{N}^* хувьд a_m > b_m нөхцөлийг хангах эерэг бүхэл тооны төгсгөлгүй өсөх арифметик прогресс \{a_m\} ба төгсгөлгүй өсөх геометр прогресс \{b_m\} оршихгүй бөгөөд (1)-ийг хангах тухай ярих ч хэрэггүй. Бидний энэ бодлогод авч үзэж буй зүйл бол төгсгөлөг дарааллууд юм. Гол санаа нь хуваарийг 1-тэй ойролцоо байлгаж, дараалсан гишүүдийн хооронд хангалттай зай үлдээх явдал юм.

Дараах томьёогоор тодорхойлогдох \{a_n\} ба \{b_n\} дарааллуудыг авч үзье: \begin{aligned} b_1 &= x^n, \quad b_2 = x^{n-1}(1 + x), \quad \dots, \quad b_n = x(1 + x)^{n-1}; \\ a_m &= x^{n-1}(1 + x) - 1 + (m - 1)x^{n-1}, \quad m = 1, 2, \dots, n. \end{aligned} Энд x нь тодорхойгүй эерэг бүхэл тоо юм. Тэгвэл \{a_m\} нь x^{n-1} ялгавартай арифметик прогресс, харин \{b_m\} нь 1 + \frac{1}{x} хуваарьтай геометр прогресс болно. Иймд (1) биелэхээр тийм эерэг бүхэл x тоо оршино гэдгийг батлахад л хангалттай.

Нэг талаас 1 \leqslant m \leqslant n хувьд a_m = x^n + x^{n-1} - 1 + (m - 1)x^{n-1} тул x > 1 үед a_m > x^n байна. Иймд: a_{m+1} = a_m + x^{n-1} < a_m + \frac{a_m}{x} = a_m\left(1 + \frac{1}{x}\right). a_1 = b_2 - 1 < b_2 бөгөөд \{b_n\} нь 1 + \frac{1}{x} хуваарьтай геометр прогресс гэдгийг тооцвол 1 \leqslant m \leqslant n - 1 хувьд a_m < b_{m+1} гэж гарна.

Нөгөө талаас аливаа 1 \leqslant m \leqslant n хувьд b_m < a_m биелэх x \in \mathbf{N}^* (x > 1) оршихыг баталъя.
Үнэхээр: \begin{aligned} b_m < a_m &\iff x^{n-m+1}(1 + x)^{m-1} < x^n + m x^{n-1} - 1 \\ &\iff x^n + C_{m-1}^{m-2} x^{n-1} + C_{m-1}^{m-3} x^{n-2} + \dots + C_{m-1}^0 x^{n-m+1} < x^n + m x^{n-1} - 1 \\ &\iff C_{m-1}^{m-3} x^{n-2} + \dots + C_{m-1}^0 x^{n-m+1} < x^{n-1} - 1 \\ &\iff x\left(C_{m-1}^{m-3} x^{n-3} + \dots + C_{m-1}^0 x^{n-m}\right) < x^{n-1} - 1. \tag{2} \end{aligned} n \geqslant m тул: C_{n-1}^{m-3} x^{n-3} + \dots + C_{n-1}^{m-1} x^{n-m} + C_{n-1}^1 x + C_{n-1}^0 \geqslant C_{m-1}^{m-3} x^{n-3} + \dots + C_{m-1}^{m-1} x^{n-m} гэж гарна. Иймд хэрэв x\left(C_{n-1}^{n-3} x^{n-3} + \dots + C_{n-1}^1 x + C_{n-1}^0\right) < x^{n-1} - 1 \tag{3} биелбэл (2) биелнэ.
(3)-ийн зүүн тал нь x-ийн хувьд n - 2 зэргийн олон гишүүнт, харин баруун тал нь x-ийн хувьд n - 1 зэргийн олон гишүүнт юм. Тиймээс x хангалттай их үед (3) биелнэ.
Дүгнэж хэлбэл, нөхцөлийг хангах дарааллууд оршино.

NoteЖишээ 6

k (k \geqslant 2) нь өгөгдсөн эерэг бүхэл тоо байг. Аливаа 1 \leqslant i \leqslant k хувьд a_i ба d_i нь эерэг бүхэл тоонууд юм. \{a_i + n d_i\} (n = 0, 1, 2, \dots) арифметик прогресст харгалзах олонлогийг A_i = \{a_i + n d_i \mid n = 0, 1, 2, \dots\} (1 \leqslant i \leqslant k) гэе. A_1, A_2, \dots, A_k нь \mathbf{N}^*-ийн k-хуваалт болдог байг (өөрөөр хэлбэл, A_1, A_2, \dots, A_k-ийн дурын хоёрынх нь огтлолцол хоосон бөгөөд A_1 \cup \dots \cup A_k = \mathbf{N}^*). Дараах хоёр тэнцэтгэлийг батал:

  1. \frac{1}{d_1} + \dots + \frac{1}{d_k} = 1;
  2. \frac{a_1}{d_1} + \dots + \frac{a_k}{d_k} = \frac{k + 1}{2}.

Баталгаа. Үүсгэгч функцийн аргыг ашиглая. Бодлогын нөхцөлөөс |x| < 1 үед \sum_{m=1}^{+\infty} x^m = \sum_{i=1}^k \left(\sum_{n=0}^{+\infty} x^{a_i + n d_i}\right) гэдэг нь мөрдөн гарна. Төгсгөлгүй буурах геометр прогрессийн нийлбэрийн томьёогоор: \frac{x}{1 - x} = \sum_{i=1}^k \frac{x^{a_i}}{1 - x^{d_i}}. Иймд: x = \sum_{i=1}^k \frac{x^{a_i}}{1 + x + \dots + x^{d_i - 1}}. \tag{1} x нь 1 рүү зүүн талаас тэмүүлэх үеийн хязгаарыг хоёр талаас авбал \sum_{i=1}^k \frac{1}{d_i} = 1 гарна. Иймд (1) биелнэ.

Одоо (1)-ийн хоёр талаас x-ээр уламжлал авбал: 1 = \sum_{i=1}^k \frac{a_i x^{a_i - 1}(1 + x + \dots + x^{d_i - 1}) - x^{a_i}(0 + 1 + 2x + \dots + (d_i - 1)x^{d_i - 2})}{(1 + x + \dots + x^{d_i - 1})^2}. Дараа нь x нь 1 рүү зүүн талаас тэмүүлэх үеийн хязгаарыг авбал: 1 = \sum_{i=1}^k \frac{a_i d_i - (1 + 2 + \dots + (d_i - 1))}{d_i^2}. Эндээс: \begin{aligned} \sum_{i=1}^k \frac{a_i}{d_i} &= 1 + \sum_{i=1}^k \frac{(d_i - 1)d_i}{2d_i^2} \\ &= 1 + \frac{1}{2}\sum_{i=1}^k \left(1 - \frac{1}{d_i}\right) \\ &= 1 + \frac{1}{2}(k - 1) = \frac{k + 1}{2}. \end{aligned} Энд бид (1)-ийг ашиглалаа.
Тиймээс өгүүлбэр үнэн.

Тайлбар. Өмнөх параграфийн Жишээ 6-тай харьцуулахад бид энд төгсгөлгүй цувааны онолыг ашигласан бөгөөд энэ нь үүсгэгч функцийг хэрэглэх чухал ур чадвар юм. Бид 7 дугаар параграфт үүсгэгч функц гэж юу болох, түүнийг хэрхэн ашиглах талаар дэлгэрэнгүй авч үзэх болно.
