Дасгал 1-ийн бодолт

  1. Энэхүү хоосон биш төгсгөлөг олонлогийн элементийн тоо n-ээр математикийн индукц хэрэглэе. Уг олонлогийг S_n гэж тэмдэглэе. n = 1 үед түүний дэд олонлогуудыг \varnothing, S_1 гэж байрлуулахад шаардлага хангагдана. Одоо n үед өгүүлбэр үнэн, өөрөөр хэлбэл S_n-ийн дэд олонлогуудыг зэрэгцээ олонлогуудын элементийн тооны ялгавар нь 1 байхаар A_1, A_2, \dots, A_{2^n} гэж сэлгэн байрлуулж чадна гэж таамаглая. S_{n+1} = \{a_1, \dots, a_{n+1}\} олонлогийг авч үзье. Түүний n элементтэй S_n = \{a_1, \dots, a_n\} дэд олонлогийн хувьд индукцийн таамаглал ёсоор шаардлагыг хангах A_1, \dots, A_{2^n} сэлгэмэл оршино. Тэгвэл дараах сэлгэмэл: A_1, \dots, A_{2^n}, \; A_{2^n} \cup \{a_{n+1}\}, \dots, A_1 \cup \{a_{n+1}\} нь S_{n+1}-ийн бүх дэд олонлогийн шаардлагыг хангах сэлгэмэл болно.

    Тайлбар. Бидний энд байгуулсан дэд олонлогуудын сэлгэмэлд зэрэгцээ орших дурын хоёр дэд олонлогийн элементийн тоо яг нэгээр зөрж байна. Энэ нь бодлогод шаардсанаас ч илүү хүчтэй үр дүн юм.

  2. k = 0 үед өгүүлбэр үнэн болох нь илэрхий. k > 0 тохиолдолд батлах дүгнэлт нь \frac{a_k}{k} \leqslant \frac{a_n}{n} гэсэнтэй эквивалент бөгөөд энэ нь дараах өгүүлбэрийн мөрдөлгөө болно: аливаа k \geqslant 0 хувьд ямагт (k + 1)a_k \leqslant k a_{k+1}. \tag{1} k-ээр индукцлэн (1) биелэхийг баталъя: k = 0 үед a_0 = 0 гэдгээс (1) биелнэ. Одоо k үед (1) үнэн гэж таамаглавал бодлогын нөхцөлөөс: \begin{aligned} (k + 2)a_{k+1} &= 2(k + 1)a_{k+1} - k a_{k+1} \leqslant 2(k + 1)a_{k+1} - (k + 1)a_k \\ &= (k + 1)(2a_{k+1} - a_k) \leqslant (k + 1)a_{k+2}. \end{aligned} Иймд k + 1 үед (1) мөн үнэн. Өгүүлбэр батлагдлаа.

  3. n = 1 үед a_1^2 \leqslant a_1 - a_2 < a_1 тул a_1 < 1, мөн үүний зэрэгцээ a_2 \leqslant a_1 - a_1^2 = \frac{1}{4} - \left(a_1 - \frac{1}{2}\right)^2 \leqslant \frac{1}{4} < \frac{1}{2}. Иймд n = 1, 2 үед өгүүлбэр үнэн. Одоо n (n \geqslant 2) үед өгүүлбэр үнэн гэж таамаглавал a_{n+1} \leqslant a_n - a_n^2 = \frac{1}{4} - \left(\frac{1}{2} - a_n\right)^2. Индукцийн таамаглал ёсоор a_n < \frac{1}{n} \leqslant \frac{1}{2} тул \frac{1}{2} - a_n > \frac{1}{2} - \frac{1}{n} \geqslant 0 гэдгийг ажиглая. Иймд: a_{n+1} < \frac{1}{4} - \left(\frac{1}{2} - \frac{1}{n}\right)^2 = \frac{1}{n} - \frac{1}{n^2} = \frac{n - 1}{n^2} < \frac{1}{n + 1}, өөрөөр хэлбэл n + 1 үед өгүүлбэр үнэн. Өгүүлбэр батлагдлаа.

  4. n = 2 үед өгүүлбэр илэрхий. n (n \geqslant 2) үед өгүүлбэр үнэн гэж таамаглаад n + 1 тохиолдлыг авч үзье. Индукцийн таамаглал ёсоор: \begin{aligned} &a_1 a_2^4 + a_2 a_3^4 + \dots + a_n a_{n+1}^4 + a_{n+1} a_1^4 \\ &\geqslant a_2 a_1^4 + a_3 a_2^4 + \dots + a_n a_{n-1}^4 + a_1 a_n^4 - a_n a_1^4 + a_n a_{n+1}^4 + a_{n+1} a_1^4. \end{aligned} n + 1 үед өгүүлбэр үнэн болохыг батлахын тулд бид зөвхөн a_1 a_n^4 - a_n a_1^4 + a_n a_{n+1}^4 + a_{n+1} a_1^4 \geqslant a_{n+1} a_n^4 + a_1 a_{n+1}^4 \tag{1} гэдгийг батлахад хангалттай. Тооцоог хялбар болгохын тулд a_1 = x, a_n = y, a_{n+1} = z гэе; тэгвэл x < y < z болох ба (1)-ийг батлах нь x y^4 + y z^4 + z x^4 - y x^4 - z y^4 - x z^4 \geqslant 0 \tag{2} тэнцэтгэл бишийг батлахтай эквивалент. (2)-ын зүүн талыг хувиргавал: \begin{aligned} &x y(y^3 - x^3) + y z(z^3 - y^3) - z x(z^3 - x^3) \\ &= (x y - z x)(y^3 - x^3) + (y z - z x)(z^3 - y^3) \\ &= -x(z - y)(y - x)(y^2 + xy + x^2) + z(y - x)(z - y)(z^2 + zy + y^2) \\ &= (y - x)(z - y)(z^3 + z^2 y + z y^2 - x y^2 - x^2 y - x^3) \\ &= (y - x)(z - y)(z - x)(z^2 + zx + x^2 + zy + xy + y^2) \\ &= \frac{1}{2}(y - x)(z - y)(z - x)\big((x + y)^2 + (y + z)^2 + (z + x)^2\big) \geqslant 0. \end{aligned} Иймд (2) биелэх ба улмаар (1) үнэн. Өгүүлбэр n + 1 үед батлагдлаа.

  5. Бодлогын нөхцөлөөс a_{n+1} = a_n + \frac{1}{a_{n-1}} гэдгийг мэднэ. Анхны нөхцөл болон математикийн индукцийг хослуулбал аливаа n \in \mathbf{N}^* хувьд a_n > 0 байна. Тиймээс n \geqslant 2 үед a_{n+1} = a_n + \frac{1}{a_{n-1}} > a_n. a_1 < a_2 гэдэгтэй хамтатган үзвэл аливаа n \in \mathbf{N}^* хувьд a_n < a_{n+1} биелнэ. Иймд n \geqslant 2 үед: a_{n+1} = a_n + \frac{1}{a_{n-1}} > a_n + \frac{1}{a_n}. \tag{1} a_3 = \frac{a_2 a_1 + 1}{a_1} = 3 гэдгээс a_3 > \sqrt{6}, өөрөөр хэлбэл n = 3 үед a_n > \sqrt{2n} байна. Одоо n = m (m \geqslant 3) үед a_m > \sqrt{2m} үнэн гэж таамаглая. Тэгвэл (1)-ээс a_{m+1}^2 > \left(a_m + \frac{1}{a_m}\right)^2 = a_m^2 + 2 + \frac{1}{a_m^2} > a_m^2 + 2 > 2m + 2 болох тул a_{m+1} > \sqrt{2(m + 1)} гарна. Тиймээс m + 1 үед өгүүлбэр үнэн болж батлагдлаа.

  6. n = 1 үед \frac{1 + a^2}{a} = \frac{1}{a} + a \geqslant 2\sqrt{\frac{1}{a} \cdot a} = 2 гэдгээс өгүүлбэр үнэн болохыг мэднэ. Одоо n үед өгүүлбэр үнэн, өөрөөр хэлбэл \frac{1 + a^2 + \dots + a^{2n}}{a + a^3 + \dots + a^{2n-1}} \geqslant \frac{n + 1}{n} гэж таамаглавал: \frac{a + a^3 + \dots + a^{2n-1}}{1 + a^2 + \dots + a^{2n}} \leqslant \frac{n}{n + 1}. Дараах адилтгалыг ажиглая: \begin{aligned} &\frac{1 + a^2 + \dots + a^{2n+2}}{a + a^3 + \dots + a^{2n+1}} + \frac{a + a^3 + \dots + a^{2n-1}}{1 + a^2 + \dots + a^{2n}} \\ &= \frac{1 + a^2 + \dots + a^{2n+2}}{a(1 + a^2 + \dots + a^{2n})} + \frac{a + a^3 + \dots + a^{2n-1}}{1 + a^2 + \dots + a^{2n}} \\ &= \frac{1 + a^2 + \dots + a^{2n+2} + a(a + a^3 + \dots + a^{2n-1})}{a(1 + a^2 + \dots + a^{2n})} \\ &= \frac{(1 + a^2 + \dots + a^{2n}) + a^2(1 + a^2 + \dots + a^{2n})}{a(1 + a^2 + \dots + a^{2n})} \\ &= \frac{a^2 + 1}{a} = a + \frac{1}{a} \geqslant 2. \end{aligned} Иймд: \frac{1 + a^2 + \dots + a^{2n+2}}{a + a^3 + \dots + a^{2n+1}} \geqslant 2 - \frac{n}{n + 1} = \frac{n + 2}{n + 1}. Өөрөөр хэлбэл, n + 1 үед өгүүлбэр үнэн. Баталгаа дуусав.

  7. n = 2 үед 2^{10} > 1000 тул \lg 2 > \frac{3}{10} болж өгүүлбэр үнэн. Одоо n (n \geqslant 2) үед өгүүлбэр үнэн гэж таамаглая. Кошийн (AM-GM) тэнцэтгэл биш ёсоор \frac{1 + 2 + \dots + n}{n} > \sqrt[n]{1 \times 2 \times \dots \times n}, өөрөөр хэлбэл n + 1 > 2(n!)^{\frac{1}{n}} байна. Тэгвэл: \begin{aligned} \lg((n + 1)!) &> \lg\big((n!) \cdot 2(n!)^{\frac{1}{n}}\big) \\ &= \lg 2 + \frac{n + 1}{n}\lg(n!) \\ &> \lg 2 + \frac{n + 1}{n} \times \frac{3n}{10}\left(\frac{1}{2} + \dots + \frac{1}{n}\right) \\ &> \frac{3}{10} + \frac{3(n + 1)}{10}\left(\frac{1}{2} + \dots + \frac{1}{n}\right) \\ &= \frac{3(n + 1)}{10}\left(\frac{1}{2} + \dots + \frac{1}{n + 1}\right). \end{aligned} Иймд n + 1 үед өгүүлбэр үнэн. Баталгаа дуусав.

  8. n = 1 үед a_1^3 = a_1^2 бөгөөд a_1 > 0 тул a_1 = 1, өөрөөр хэлбэл n = 1 үед өгүүлбэр үнэн. Одоо 1, 2, \dots, n - 1 хувьд өгүүлбэр үнэн, өөрөөр хэлбэл a_k = k (k = 1, 2, \dots, n - 1) гэж таамаглая. Тэгвэл: \left(\sum_{k=1}^{n-1} k^3\right) + a_n^3 = \sum_{k=1}^n a_k^3 = \left(\sum_{k=1}^n a_k\right)^2 = \left(\left(\sum_{k=1}^{n-1} k\right) + a_n\right)^2. Иймд a_n^3 = a_n^2 + n(n - 1)a_n болох ба үүнийг бодвол a_n = 0, -(n - 1) эсвэл n гарна. a_n > 0 гэдгийг тооцвол a_n = n болно. Иймд n-ийн хувьд өгүүлбэр үнэн. Баталгаа дуусав.

  9. Ерөнхий чанарыг алдагдуулахгүйгээр a_1 < a_2 < \dots < a_n гэж эрэмбэлье. n = 1 үед a_1^2 \geqslant \frac{2 + 1}{3}a_1 тэнцэтгэл биш үнэн. n үед тэнцэтгэл биш үнэн, өөрөөр хэлбэл a_1^2 + \dots + a_n^2 \geqslant \frac{2n + 1}{3}(a_1 + \dots + a_n) гэж таамаглаад n + 1 тохиолдлыг авч үзье. Бид зөвхөн a_{n+1}^2 \geqslant \frac{2}{3}(a_1 + \dots + a_n) + \frac{2n + 3}{3}a_{n+1} болохыг батлахад хангалттай (энд a_1 < a_2 < \dots < a_n < a_{n+1} ба a_i \in \mathbf{N}^*).
    a_n \leqslant a_{n+1} - 1, a_{n-1} \leqslant a_n - 1 \leqslant a_{n+1} - 2, \dots, a_1 \leqslant a_{n+1} - n гэдгийг тооцвол бид зөвхөн a_{n+1}^2 \geqslant \frac{2}{3}\sum_{k=1}^n (a_{n+1} - k) + \frac{2n + 3}{3}a_{n+1} болохыг батлахад хангалттай бөгөөд энэ нь a_{n+1}^2 - \frac{4n + 3}{3}a_{n+1} + \frac{n(n + 1)}{3} \geqslant 0, өөрөөр хэлбэл (a_{n+1} - (n + 1))\left(a_{n+1} - \frac{n}{3}\right) \geqslant 0 гэсэнтэй эквивалент. Энэ тэнцэтгэл бишийг a_{n+1} \geqslant a_1 + n \geqslant n + 1 гэдгийг ашиглан баталж болно. Иймд анхны тэнцэтгэл биш n + 1 үед үнэн. Баталгаа дуусав.

  10. Рекуррент томьёоноос a_{n+1}^2 = a_{n-1} a_{n+2} (n = 2, 3, \dots) гэдгийг мэднэ. Анхны нөхцөл болон математикийн индукцээс a_n \neq 0 гэж гарна. Дээрхийг хувиргавал: \frac{a_{n+2}}{a_{n+1} a_n} = \frac{a_{n+1}}{a_n a_{n-1}}, \quad n = 2, 3, \dots Үүнийг рекуррентээр ухрааж хэрэглэвэл \frac{a_{n+2}}{a_{n+1} a_n} = \frac{a_{n+1}}{a_n a_{n-1}} = \dots = \frac{a_3}{a_2 a_1} = 2, өөрөөр хэлбэл a_{n+2} = 2a_{n+1} a_n (n = 2, 3, \dots) болно. Рекуррент илэрхийлэл болон a_1, a_2, a_3 \in \mathbf{Z} гэдгээс a_n нь бүгд бүхэл тоонууд болох ба \frac{a_{n+2}}{a_{n+1}} = 2a_n (энэ тэгшитгэл n = 1 үед мөн биелэхийг анхаарна уу). Аливаа n \in \mathbf{N}^* хувьд \frac{a_{n+2}}{a_{n+1}} нь тэгш тоо болохыг мэднэ.
    Тэгвэл a_n = \left(\frac{a_n}{a_{n-1}}\right) \cdot \left(\frac{a_{n-1}}{a_{n-2}}\right) \cdots \left(\frac{a_2}{a_1}\right) \cdot a_1 нь n ширхэг тэгш тооны үржвэр болно. Иймд 2^n \mid a_n.

  11. Рекуррент томьёоноос a_{n+1} - k = a_n(a_n - k) тул a_n - k = a_{n-1}(a_{n-1} - k) = a_{n-1} a_{n-2}(a_{n-2} - k) = \dots = a_{n-1} \cdots a_1(a_1 - k) = a_{n-1} \cdots a_1, өөрөөр хэлбэл a_n = a_{n-1} \cdots a_1 + k. \tag{1} Дурын m, n \in \mathbf{N}^* (m \neq n) хувьд ерөнхий чанарыг алдагдуулахгүйгээр m < n гэе. (1)-ээс: (a_n, a_m) = (a_{n-1} \cdots a_1 + k, a_m) = (k, a_m). Дараа нь аливаа m \in \mathbf{N}^* хувьд ямагт a_m \equiv 1 \pmod{k} биелэхийг баталъя.
    m = 1 үед a_1 = k + 1 гэдгээс дүгнэлт зөв. m үед зөв буюу a_m \equiv 1 \pmod{k} гэж таамаглавал a_{m+1} = a_m^2 - k a_m + k \equiv a_m^2 \equiv 1^2 \equiv 1 \pmod{k} болно. Иймд бүх m \in \mathbf{N}^* хувьд a_m \equiv 1 \pmod{k} байна.
    Дээрх дүгнэлтүүдээс (a_m, k) = 1, улмаар (a_n, a_m) = 1 болно.

Нэгдүгээр параграфийн Жишээ 5-ыг үзнэ үү. \{a_n\} дарааллын эхний 21 гишүүнийг тооцоолж үзвэл дараалан: \begin{gathered} 1, \; 2, \; 3, \; 5, \; 7, \; 9, \; 12, \; 15, \; 18, \; 23, \; 28, \; 33, \\ 40, \; 47, \; 54, \; 63, \; 72, \; 81, \; 93, \; 105, \; 117 \end{gathered} гарах ба эдгээрийн дотроос a_1, a_2, a_3, a_4, a_{11}, a_{20} гишүүд нь харгалзан 2, 3, 5, 7, 11, 13-ын хуваагдагчид болно. Иймд дурын p \in \{2, 3, 5, 7, 11, 13\} хувьд p-д хуваагддаг a_n гишүүн оршино.
    Хэрэв a_{3n-1} \equiv 0 \pmod{p} бол a_n-ээс эхлэн p-ийн дараагийн хуваагдагчийг оллоо. Хэрэв a_{3n-1} \not\equiv 0 \pmod{p} бол рекуррент томьёо болон a_n \equiv 0 \pmod{p} гэдгээс a_{3n+2} \equiv a_{3n+1} \equiv a_{3n} \equiv a_{3n-1} \pmod{p} болно.
    Тэдгээрийг p-д хуваахад гарах үлдэгдлийг r гэе. Өмнө дурдсан жишээний адилаар авч үзвэл доорх 13 ширхэг тоо: a_{9n-4}, \; a_{9n-3}, \; \dots, \; a_{9n+8} нь модуль p-ээр a_{9n-4}, a_{9n-4} + r, \dots, a_{9n-4} + 12r тоонуудтай жишүү байна. p \leqslant 13 тул эдгээр 13 тоо нь модуль p-ээр үлдэгдлийн ядаж нэг бүрэн системийг хамарна. Тиймээс a_n-ээс эхлэн p-ийн дараагийн хуваагдагчийг олж чадна. Өгүүлбэр батлагдлаа.

  13. n-ээр индукцлэе.   33. Бодлогын нөхцөлөөс P(x) = a_n(x + \beta_1)(x + \beta_2)\cdots(x + \beta_n) гэж тавьж болно. Энд \beta_i \geqslant 1 (i = 1, 2, \dots, n) ба a_n \neq 0.
    a_0^2 + a_1 a_n = a_n^2 + a_0 a_{n-1} гэдгийг ашиглавал: a_n^2\left(\prod_{i=1}^n \beta_i\right)^2 + a_n^2\left(\prod_{i=1}^n \beta_i\right)\sum_{i=1}^n \frac{1}{\beta_i} = a_n^2 + \left(\prod_{i=1}^n \beta_i\right)\left(\sum_{i=1}^n \beta_i\right)a_n^2. Тэгвэл: \prod_{i=1}^n \beta_i - \frac{1}{\prod_{i=1}^n \beta_i} = \sum_{i=1}^n \beta_i - \sum_{i=1}^n \frac{1}{\beta_i}. \tag{1}

    Дараа нь n-ээр математикийн индукц хэрэглэн дараах өгүүлбэрийг баталъя: \beta_i \geqslant 1 (i = 1, 2, \dots, n) үед ямагт \prod_{i=1}^n \beta_i - \frac{1}{\prod_{i=1}^n \beta_i} \geqslant \sum_{i=1}^n \beta_i - \sum_{i=1}^n \frac{1}{\beta_i} биелэх бөгөөд «=» тэмдэг нь зөвхөн \beta_1, \dots, \beta_n тоонуудын дотор n - 1 ширхэг нь 1-тэй тэнцүү байх үед л биелнэ.

    n = 2 үед \beta_1, \beta_2 \geqslant 1 бол дараах эквивалент хамаарал биелнэ: \begin{aligned} \beta_1 \beta_2 - \frac{1}{\beta_1 \beta_2} &\geqslant (\beta_1 + \beta_2) - \left(\frac{1}{\beta_1} + \frac{1}{\beta_2}\right) \\ \iff (\beta_1 \beta_2)^2 - 1 &\geqslant (\beta_1 + \beta_2)(\beta_1 \beta_2 - 1) \\ \iff (\beta_1 \beta_2 - 1)(\beta_1 - 1)(\beta_2 - 1) &\geqslant 0. \end{aligned} Иймд n = 2 үед дээрх өгүүлбэр биелнэ.
    n = k үед өгүүлбэр биелнэ гэж таамаглаад n = k + 1 тохиолдолд \alpha = \beta_k \beta_{k+1} гэе. Индукцийн таамаглал ёсоор: \prod_{i=1}^{k+1} \beta_i - \frac{1}{\prod_{i=1}^{k+1} \beta_i} \geqslant \left(\sum_{i=1}^{k-1} \beta_i - \sum_{i=1}^{k-1} \frac{1}{\beta_i}\right) + \alpha - \frac{1}{\alpha}, энд «=» тэмдэг нь зөвхөн \beta_1, \beta_2, \dots, \beta_{k-1}, \alpha тоонуудын дотор k - 1 ширхэг нь 1-тэй тэнцүү байх үед л биелнэ.
    n = 2 тохиолдлоос: \alpha - \frac{1}{\alpha} = \beta_k \beta_{k+1} - \frac{1}{\beta_k \beta_{k+1}} \geqslant \beta_k + \beta_{k+1} - \frac{1}{\beta_k} - \frac{1}{\beta_{k+1}}. Тиймээс: \prod_{i=1}^{k+1} \beta_i - \frac{1}{\prod_{i=1}^{k+1} \beta_i} \geqslant \sum_{i=1}^{k+1} \beta_i - \sum_{i=1}^{k+1} \frac{1}{\beta_i}, энд «=» тэмдэг нь зөвхөн \beta_1, \dots, \beta_{k-1}, \alpha тоонуудын дотор k - 1 ширхэг нь 1-тэй тэнцүү бөгөөд \beta_k, \beta_{k+1}-ийн аль нэг нь 1 байх үед л биелнэ. Энэ нь «\beta_1, \dots, \beta_{k+1} тоонуудын дотор k ширхэг нь 1-тэй тэнцүү байх» гэсэн нөхцөлтэй эквивалент.

    Дээрх дүгнэлт болон (1)-ээс P(x) = a_n(x + 1)^{n-1}(x + \beta) (a_n \neq 0, \beta \geqslant 1) хэлбэрийн олон гишүүнтүүд нь нөхцөлийг хангах бүх олон гишүүнт болохыг мэднэ.

  38. Лемм. Аливаа n \in \mathbf{N}^* хувьд ямагт \begin{aligned} &\left\{\frac{\beta_1}{2} + \frac{\beta_2}{2^2} + \dots + \frac{\beta_n}{2^n} \;\middle|\; \beta_i \in \{-1, 1\}, \; i = 1, 2, \dots, n\right\} \\ &= \left\{\frac{j}{2^n} \;\middle|\; j \text{ нь сондгой тоо бөгөөд } |j| < 2^n\right\} \end{aligned} биелнэ.

    n = 1 үед лемм илэрхий үнэн. n-ээс бага бүх эерэг бүхэл тооны хувьд лемм үнэн гэж таамаглаад n тохиолдлыг авч үзье.

Цаашилбал: \left|\frac{j}{2^n}\right| = \left|\sum_{i=1}^n \frac{\beta_i}{2^i}\right| \leqslant \sum_{i=1}^n \frac{|\beta_i|}{2^i} = \sum_{i=1}^n \frac{1}{2^i} = 1 - \frac{1}{2^n} < 1, иймд |j| < 2^n.
    Урвуугаар, сондгой j (|j| < 2^n) тооны хувьд \frac{j - 1}{2} ба \frac{j + 1}{2} тоонуудын нэг нь сондгой, нөгөө нь тэгш болохыг ажиглая. Тиймээс индукцийн таамаглал ёсоор \frac{\beta_1}{2} + \frac{\beta_2}{2^2} + \dots + \frac{\beta_{n-1}}{2^{n-1}} = \frac{j_0}{2^{n-1}} байх \beta_1, \beta_2, \dots, \beta_{n-1} \in \{-1, 1\} оршино.

    (2) S = \sum_{\substack{a, b \in A_n \\ a < b}} ab гэж тэмдэглэвэл S = \frac{1}{2}\left(\left(\sum_{a \in A_n} a\right)^2 - \sum_{a \in A_n} a^2\right) байна.
    A_n дахь 1 + \frac{j}{2^{\lfloor \frac{n}{2} \rfloor}} + \frac{k}{2^{\lceil \frac{n}{2} \rceil}}\sqrt{2} ба 1 - \frac{j}{2^{\lfloor \frac{n}{2} \rfloor}} - \frac{k}{2^{\lceil \frac{n}{2} \rceil}}\sqrt{2} элементүүдийг хослон нэмж, (1)-ийн дүгнэлтийг ашиглавал \sum_{a \in A_n} a = 2^n гэдгийг мэднэ.
    Цаашилбал, хэрэв X, Y хоёулаа төгсгөлөг олонлогууд бөгөөд \sum_{x \in X} x = \sum_{y \in Y} y = 0 бол \sum_{x \in X}\sum_{y \in Y} (1 + x + y)^2 = |X| \cdot |Y| + |Y| \cdot \sum_{x \in X} x^2 + |X| \cdot \sum_{y \in Y} y^2 биелэх чанарыг ашиглая. A_n-ийн бүтцийг тооцвол: \begin{aligned} \sum_{a \in A_n} a^2 &= \sum_{\substack{j \text{ сондгой} \\ |j| < 2^{\lfloor \frac{n}{2} \rfloor}}} \sum_{\substack{k \text{ сондгой} \\ |k| < 2^{\lceil \frac{n}{2} \rceil}}} \left(1 + \frac{j}{2^{\lfloor \frac{n}{2} \rfloor}} + \frac{k}{2^{\lceil \frac{n}{2} \rceil}}\sqrt{2}\right)^2 \\ &= 2^{\lceil \frac{n}{2} \rceil} \cdot 2^{\lfloor \frac{n}{2} \rfloor} + \sum_{\substack{j \text{ сондгой} \\ |j| < 2^{\lfloor \frac{n}{2} \rfloor}}} \frac{j^2 \cdot 2^{\lceil \frac{n}{2} \rceil}}{2^{2\lfloor \frac{n}{2} \rfloor}} + \sum_{\substack{k \text{ сондгой} \\ |k| < 2^{\lceil \frac{n}{2} \rceil}}} \frac{2k^2 \cdot 2^{\lfloor \frac{n}{2} \rfloor}}{2^{2\lceil \frac{n}{2} \rceil}} \\ &= 2^n + \frac{1}{3}\left(\frac{2^{\lceil \frac{n}{2} \rceil} \cdot 2^{\lfloor \frac{n}{2} \rfloor}(2^{2\lfloor \frac{n}{2} \rfloor} - 1)}{2^{2\lfloor \frac{n}{2} \rfloor}} + \frac{2^{\lfloor \frac{n}{2} \rfloor} \cdot 2^{\lceil \frac{n}{2} \rceil}(2^{2\lceil \frac{n}{2} \rceil} - 1)}{2^{2\lceil \frac{n}{2} \rceil - 1}}\right) \\ &= 2^n + \frac{2^n}{3}\left(3 - \frac{1}{2^{2\lfloor \frac{n}{2} \rfloor}} - \frac{1}{2^{2\lceil \frac{n}{2} \rceil - 1}}\right) \\ &= 2^{n+1} - 1. \end{aligned} Дээрхийг нэгтгэвэл (1)-ийн хариу нь 2^n, харин (2)-ын хариу нь \frac{1}{2}(2^{2n} - 2^{n+1} + 1) байна.

Сүүлийн гишүүн нь 3 байх задаргаануудаас сүүлийн 3-ыг хасахад n - 3-ийн бүх эрэмбэлэгдсэн задаргаа гарна. Сүүлийн гишүүн нь 4 байх задаргаануудаас сүүлийн 4-ийг хасахад n - 4-ийн бүх эрэмбэлэгдсэн задаргаа гарна. n \geqslant 5 тул задаргаа орших тохиолдолд ядаж хоёр гишүүнтэй байна. Тэгвэл n-ийн эрэмбэлэгдсэн задаргаануудаас тогтох матрицын эхний баганын бүх элементийн нийлбэр нь x_{n-3} + x_{n-4} болно (энд индукцийн таамаглалыг ашиглалаа). Иймд n-ийн хувьд лемм үнэн болж батлагдлаа.

    Үндсэн асуултдаа эргэн оръё: p = 2, 3 үед x_p = 0 тул өгүүлбэр үнэн. Анхны p (p \geqslant 5) тооны хувьд p-г 3 ба 4-ийн эрэмбэлэгдсэн задаргаануудад хуваахад үүсэх матрицыг M гэе. Тэгвэл M-ийн мөр бүрийн урт l нь \frac{p}{4} \leqslant l \leqslant \frac{p}{3} нөхцөлийг хангана.
    M матриц дахь ижил урттай бүх мөрөөс тогтох T дэд матрицыг шинжилье: T-ийн эхний баганын бүх элементийн нийлбэрийг s гэе. T-ийн мөр бүрд 3 ба 4 хоёулаа зэрэг оролцох ёстой (зөвхөн 3 эсвэл зөвхөн 4 орсон бол p нь 3 эсвэл 4-ийн хуваагдагч болж анхны тоо биш болно). Иймд тухайн мөр дэх 3 ба 4-ийн байрыг солиход мөн T-ийн өөр нэг мөр үүснэ. Энэ нь T-ийн дурын хоёр баганын элементүүдийн нийлбэр тэнцүү болохыг харуулна. T-ийн багана бүрийн нийлбэрийг s гэе. T-ийн баганын тоо l бол T-ийн бүх тооны нийлбэр sl болох ба мөр бүрийн тоонуудын нийлбэр p тул sl нь p-д хуваагдана. \frac{p}{4} \leqslant l \leqslant \frac{p}{3} тул p \mid s гэдгийг мэднэ.
    Дээрх шинжилгээнээс M матрицын эхний баганын бүх тооны нийлбэр мөн p-ийн хуваагдагч буюу p \mid x_p болно. Өгүүлбэр хүчинтэй.

  40. a_1, \dots, a_n нь шаардлагыг хангах эерэг бүхэл тоонууд байг. Тэгвэл (1) нөхцөлөөс 1 \leqslant k \leqslant n хувьд ямагт a_k > a_{k-1} биелнэ (эс тэгвээс зүүн тал \geqslant 1, баруун тал < 1 болно). Тиймээс a_k > 1 байна. Иймд (2) нөхцөлөөс \frac{a_{k-1}}{a_k(a_k - 1)} \geqslant \frac{a_k}{a_{k+1} - 1} буюу \frac{a_{k-1}}{a_k - 1} - \frac{a_{k-1}}{a_k} \geqslant \frac{a_k}{a_{k+1} - 1} болох тул \frac{a_{k-1}}{a_k} \leqslant \frac{a_{k-1}}{a_k - 1} - \frac{a_k}{a_{k+1} - 1} гарна. k = i + 1, \dots, n - 1 утгуудаар нэмбэл: \frac{a_i}{a_{i+1}} + \dots + \frac{a_{n-1}}{a_n} \leqslant \frac{a_i}{a_{i+1} - 1} - \frac{a_{n-1}}{a_n - 1} + \frac{a_{n-1}}{a_n} < \frac{a_i}{a_{i+1} - 1}. \tag{1} (1)-д i = 0 гэж орлуулбал (1) нөхцөл ёсоор \frac{1}{a_1} \leqslant \frac{99}{100} = \sum_{i=0}^{n-1} \frac{a_i}{a_{i+1}} < \frac{1}{a_1 - 1} болох тул a_1 = 2. Үүнтэй адилаар (1)-д i = 1 гэж орлуулбал: \frac{1}{a_2} \leqslant \frac{1}{a_1}\left(\frac{99}{100} - \frac{1}{a_1}\right) < \frac{1}{a_2 - 1} буюу \frac{1}{a_2} \leqslant \frac{49}{200} < \frac{1}{a_2 - 1} болох тул a_2 = 5 гарна. Энэ үйлдлийг давтан (1)-д i = 2, 3 гэж орлуулбал a_3 = 56, a_4 = 25 \times 56^2 = 78\,400 болно. Тиймээс: \frac{1}{a_5} \leqslant \frac{1}{a_4}\left(\frac{99}{100} - \frac{1}{2} - \frac{2}{5} - \frac{5}{56} - \frac{56}{25 \times 56^2}\right) = 0 болох тул a_5 оршихгүй.
    Дээрхийг нэгтгэвэл зөвхөн n = 4 үед л ийм дараалал орших бөгөөд харгалзах гишүүд нь a_1 = 2, a_2 = 5, a_3 = 56, a_4 = 78\,400 байна.

  41. x_n = n y_n (n = 2, 3, \dots) гэе; тэгвэл x_2 = 2, x_3 = 3 болох ба n \geqslant 3 үед (n - 2)x_{n+1} = (n^2 - n - 1)x_n - (n - 1)^2 x_{n-1}, өөрөөр хэлбэл \frac{x_{n+1} - x_n}{n - 1} = (n - 1) \cdot \frac{x_n - x_{n-1}}{n - 2} \tag{1} болно. (1)-ийг ашиглан рекуррентээр үндэслэвэл: \begin{aligned} \frac{x_{n+1} - x_n}{n - 1} &= (n - 1) \cdot \frac{x_n - x_{n-1}}{n - 2} = (n - 1)(n - 2) \cdot \frac{x_{n-1} - x_{n-2}}{n - 3} \\ &= \dots = (n - 1)\cdots 2 \cdot \frac{x_3 - x_2}{1} = (n - 1)!, \end{aligned} эндээс x_{n+1} - x_n = n! - (n - 1)! гарна. Гишүүдийг хураан нийлбэрлэвэл: \begin{aligned} x_n &= x_2 + \sum_{k=2}^{n-1} (x_{k+1} - x_k) = x_2 + \sum_{k=2}^{n-1} (k! - (k - 1)!) \\ &= x_2 + (n - 1)! - 1 = (n - 1)! + 1. \end{aligned} Зөвхөн n анхны тоо байх үед л n \mid (n - 1)! + 1 биелдэг гэсэн Вильсоны теорем ёсоор y_n \in \mathbf{Z} байх зайлшгүй бөгөөд хүрэлцээтэй нөхцөл нь n анхны тоо байх явдал гэдгийг мэднэ.

  42. Лемм. n, k \in \mathbf{N}^*, n \geqslant kp бол a_n = \sum_{i=0}^k C_k^i a_{n - i(p - 1) - k} \tag{1} биелнэ.

    k-аар индукцлэе. k = 1 үед (1) нь үнэндээ a_n = a_{n-1} + a_{n-p} тул k = 1 үед (1) үнэн.
    Одоо k үед (1) үнэн гэж таамаглаад k + 1 тохиолдлыг авч үзье. Тэгвэл n \geqslant (k + 1)p болох ба n - i(p - 1) - k (0 \leqslant i \leqslant k) дугааруудын хамгийн бага утга нь i = k үед хүрч n - kp \geqslant p байна. Иймд доорх нийлбэрлэх үйлдлийн гишүүн бүрд нөхцөлийн рекуррент томьёог хэрэглэж болно: \begin{aligned} a_n &= \sum_{i=0}^k C_k^i a_{n - i(p - 1) - k} \\ &= \sum_{i=0}^k C_k^i \big(a_{n - i(p - 1) - k - 1} + a_{n - i(p - 1) - k - p}\big) \\ &= C_k^0 a_{n - k - 1} + \sum_{i=1}^k C_k^i a_{n - i(p - 1) - k - 1} + \sum_{i=0}^{k-1} C_k^i a_{n - i(p - 1) - k - p} + C_k^k a_{n - (k + 1)p} \\ &= C_{k+1}^0 a_{n - (k + 1)} + \sum_{i=0}^{k-1} C_k^{i+1} a_{n - (i + 1)(p - 1) - (k + 1)} + \sum_{i=0}^{k-1} C_k^i a_{n - (i + 1)(p - 1) - (k + 1)} + C_{k+1}^{k+1} a_{n - (k + 1)p} \\ &= C_{k+1}^0 a_{n - (k + 1)} + \sum_{i=0}^{k-1} (C_k^{i+1} + C_k^i) a_{n - (i + 1)(p - 1) - (k + 1)} + C_{k+1}^{k+1} a_{n - (k + 1)p} \\ &= \sum_{i=0}^{k+1} C_{k+1}^i a_{n - (i + 1)(p - 1) - (k + 1)}. \end{aligned} Сүүлийн алхамд C_k^{i+1} + C_k^i = C_{k+1}^{i+1} адилтгалыг ашиглалаа. Иймд k + 1 үед (1) биелэх тул лемм батлагдлаа.

    Одоо леммийг ашиглан үндсэн бодлогоо бодъё. n \geqslant p^2 үед леммд k = p гэж авбал: a_n = \sum_{i=0}^p C_p^i a_{n - i(p - 1) - p}. 1 \leqslant i \leqslant p - 1 үед C_p^i \equiv 0 \pmod{p} гэдэг нь мэдэгдэж байна. Тиймээс a_n \equiv a_{n-p} + a_{n-p^2} \pmod{p} болох ба a_n = a_{n-1} + a_{n-p} гэдгийг тооцвол a_{n-1} \equiv a_{n-p^2} \pmod{p} болно. Энэ нь аливаа t \geqslant p^2 - 1 хувьд a_t \equiv a_{t + p^2 - 1} \pmod{p} биелэхийг харуулна.
    p^3 = p(p^2 - 1) + p тул a_{p^3} = a_{p + p(p^2 - 1)} \equiv a_p \pmod{p} болох ба a_p = a_0 + a_{p-1} = p - 1 гэдгийг тооцвол a_{p^3} \equiv p - 1 \pmod{p}, өөрөөр хэлбэл a_{p^3}-ийг p-д хуваахад гарах үлдэгдэл нь p - 1 байна.

Тооцоог хялбар болгохын тулд m = n - 1, b_i = a_i + 1 гэж тэмдэглэвэл 1 \leqslant a_0 \leqslant 2m болох ба a_{i+1} = \begin{cases} 2a_i, & \text{хэрэв } a_i \leqslant m \text{ бол}, \\ 2a_i - (2m + 1), & \text{хэрэв } a_i > m \text{ бол} \end{cases} болно. Тэгвэл (n + 1)-р бөмбөгийг байрлуулахдаа доорх аргыг дагана: 1, 2, \dots, i - 1 дугаартай цагаан хайрцаг тус бүрээс нэг нэг бөмбөг авч i дугаартай хайрцагт хийгээд, (n + 1)-р бөмбөгийг мөн i дугаартай хайрцагт хийнэ. Энэ байрлуулалт нөхцөлийг хангахыг хялбархан харж болно.

    Дараа нь байрлуулах арга цор ганц гэдгийг батлахын тулд мөн л n-ээр математикийн индукц хэрэглэе.
    n = 1, 2 үед цор ганц байх нь илэрхий. n (n \geqslant 2) үед цор ганц T байрлуулалт оршино гэж таамаглая.
    n + 1 \geqslant 3 үед бүх боломжит байрлуулалтын хувьд (n + 1)-р цагаан хайрцаг заавал хоосон байх ёстойг хялбархан харж болно. Тэгвэл n + 1 үед T_1 ба T_2 гэсэн хоёр байрлуулалт оршино гэе. Хоосон байгаа (n + 1)-р цагаан хайрцгийг авч хаявал T_1 ба T_2-ын хувьд эхний алхмын үйлдлийн дараа цагаан хайрцгуудад n бөмбөг, цагаан хайрцгийн тоо n болох тул хоёулаа T байрлуулалт болж хувирна.

    T_1 ба T_2 байрлуулалтад эхний үйлдэл хийгдсэн цагаан хайрцгуудын дугаар харгалзан i_1, i_2 байг. Хэрэв i_1 > i_2 бол T_1-ийн эхний үйлдлийн дараа i_2 дугаартай цагаан хайрцагт ядаж нэг бөмбөг байх бол T_2-ын эхний үйлдлийн дараа i_2 дугаартай цагаан хайрцаг хоосон байна. Тэгвэл хоёулаа T болж хувирах боломжгүй тул i_1 \leqslant i_2. Үүнтэй ижил үндэслэлээр i_2 \leqslant i_1 буюу i_1 = i_2 болно. Иймд T_1 ба T_2-ын хувьд i_1-ээс их дугаартай цагаан хайрцгууд дахь бөмбөгний тоо ижил байна. i_1-ээс бага дугаартай цагаан хайрцгууд дахь бөмбөгний тоо мөн ижил байна (эс тэгвээс T_1 ба T_2 нь нэг үйлдлийн дараа хоёулаа T болж чадахгүй). Тиймээс i_1 дугаартай хайрцаг дахь бөмбөгний тоо мөн ижил байх ёстой тул T_1 = T_2.
    Энэ нь нөхцөлийг хангах цорын ганц байрлуулалтын арга оршихыг харуулна.

  46. (1) A, B, C-ийг харгалзан 0, 1, 2-оор тэмдэглэе. Модуль 3-аар R_0, R_1, \dots дарааллын өөрчлөлтийг ажиглая.
    R_j = (x_1, \dots, x_n), R_{j+1} = (y_1, y_2, \dots, y_n) гэвэл 1 \leqslant i \leqslant n хувьд ямагт y_i \equiv -(x_i + x_{i+1}) \pmod{3} биелнэ.
    Хэрэв n тэгш тоо бол R_0 = (1, 2, 1, 2, \dots, 1, 2) гэж авбал аливаа m \geqslant 1 хувьд ямагт R_m = (0, 0, \dots, 0, 0) болно. Иймд энэ үед шаардлагыг хангах эерэг бүхэл m оршихгүй.
    Хэрэв n сондгой тоо бол (x_1, \dots, x_n) хэлбэрийн n элементтэй ялгаатай цуглуулга хамгийн олондоо 3^n ширхэг байх тул дурын R_0-ийн хувьд R_k = R_{m_{R_0} + k} байх m_{R_0} \in \mathbf{N}^* ба k \in \mathbf{N} оршино. Хэрэв k \geqslant 1 бол R_{k-1} = R_{m_{R_0} + k - 1} гэдгийг баталъя (ийм замаар ухраавал R_0 = R_{m_{R_0}} гарна).

    Үнэн хэрэгтээ R_{k-1} = (x_1, \dots, x_n), R_{m_{R_0} + k - 1} = (y_1, \dots, y_n) гэвэл R_k = R_{m_{R_0} + k} гэдгээс -(x_i + x_{i+1}) \equiv -(y_i + y_{i+1}) \pmod{3} болно. Иймд: \sum_{j=1}^n (-1)^j(x_j + x_{j+1}) \equiv \sum_{j=1}^n (-1)^j(y_j + y_{j+1}) \pmod{3}. n нь сондгой тоо гэдгийг тооцвол -x_1 + (-1)^n x_{n+1} \equiv -y_1 + (-1)^n y_{n+1} \pmod{3} буюу -2x_1 \equiv -2y_1 \pmod{3}, улмаар x_1 \equiv y_1 \pmod{3} тул x_1 = y_1 гарна. Үүнтэй ижил үндэслэлээр i \in \{2, \dots, n\} хувьд ямагт x_i = y_i болох тул R_{k-1} = R_{m_{R_0} + k - 1}.

    Дээрхээс дурын R_0-ийн хувьд R_0 = R_{m_{R_0}} байх m_{R_0} оршихыг мэдлээ. R_0 өөрчлөгдөх үед бүх m_{R_0}-ийн хамгийн бага ерөнхий хуваагдагчийг m гэж авбал дурын R_0-ийн хувьд ямагт R_0 = R_m биелнэ.
    Дээрхийг нэгтгэвэл зөвхөн n сондгой тоо байх үед л бүх нөхцөлийг хангах m оршино.

    (2) n = 3^k (k \in \mathbf{N}^*) үед (1)-д заасан нөхцөлийг хангах m-ийн хамгийн бага утга нь m = 3^k байна.
    Үнэн хэрэгтээ дурын R_0 = (x_1, \dots, x_n) хувьд R_{3^k} = (y_1, \dots, y_n) гэвэл өмнө гаргасан модуль 3-аарх хамаарлаас y_p \equiv -\sum_{i=0}^{3^k} C_{3^k}^i x_{i+p} \pmod{3} болохыг хялбархан мэднэ (энд x_{i+p}-ийн дугаарыг модуль n-ээр авна, p = 1, 2, \dots, n). Мөн 1 \leqslant i \leqslant 3^k - 1 хувьд C_{3^k}^i \equiv 0 \pmod{3} гэдгийг ажиглавал y_p \equiv -x_p - x_{3^k + p} = -2x_p \equiv x_p \pmod{3} болох тул R_{3^k} = R_0.
    Нөгөө талаас R_0 = (0, 0, \dots, 0, 1) гэж авбал 0 < m < 3^k үед R_m-ийн (3^k - m)-р компонент тэгтэй тэнцүү биш байна. Иймд (1)-ийг хангах m-ийн хамгийн бага утга нь 3^k юм.
